# 竞品价格分析 💲

战略级竞品定价情报。绘制市场位置地图、识别机会、优化你的定价策略。

## 安装

```bash
npx skills add nexscope-ai/eCommerce-Skills --skill competitor-price-analysis -g
```

## 用法示例

**市场价格全景分析：**
```
"分析 Amazon 上 20–80 美元无线耳机的竞品定价——每个价位段谁在赢？"
```

**定价缺口识别：**
```
"找出 Shopify 护肤品市场的定价缺口与机会"
```

**价格弹性分析：**
```
"分析家庭健身器材品类中竞品对价格变化的反应"
```

## 核心能力

### 1. 竞品价格地图
- 市场价格定位与分布分析
- 价位段识别与竞品聚类
- 不同价位的价值主张评估
- 按价格细分的市场份额分析

### 2. 定价缺口与机会分析
- 供给不足的价位点识别
- 高端与平价市场机会
- 新品定位的白地（white space）分析
- 价格-功能相关性评估

### 3. 价格弹性与策略情报
- 竞品调价模式分析
- 市场对价格调整的响应
- 动态定价行为评估
- 促销定价策略评估

## 工作方式

### 第 1 步：竞品价格调研与数据收集
*全面的竞品定价全景分析*

收集竞争定价情报：
- 调研竞品在各大平台的产品目录与定价结构
- 分析价格相对功能、品质与品牌定位的关系
- 绘制价位段并识别竞品聚类模式
- 收集历史定价数据与促销模式

### 第 2 步：市场分析与机会识别
*战略级定价缺口与定位分析*

分析市场定价动态：
- 识别供给不足的价位点与市场缺口
- 评估价格-价值关系与竞争优势
- 分析客户价格敏感度与购买行为模式
- 评估市场定位的机会与威胁

### 第 3 步：战略性定价建议
*数据驱动的定价策略制定*

制定定价策略建议：
- 基于竞争格局确定最优定价位置
- 识别夺取市场份额的战略性定价动作
- 制定动态定价策略与促销战术
- 建立定价监控与调整框架

## 输出格式

```
## 竞品定价分析报告
**品类：** [品类] | **平台：** [平台] | **价格区间：** $[低] - $[高]

### 市场定价概览

**价格分布分析：**
- **平价段**（$[X]-$[Y]）：占市场 [X]%，竞争[程度]
- **中端**（$[Y]-$[Z]）：占市场 [X]%，竞争[程度]
- **高端段**（$[Z]+）：占市场 [X]%，竞争[程度]
- **平均售价：** $[金额]
- **价差：** $[区间]（高低差 [X] 倍）

### 竞品价格地图

**各价位段关键竞品：**

| 竞品 | 价位点 | 市场位置 | 价值主张 | 份额估计 |
|------|--------|---------|---------|---------|
| [品牌 A] | $[金额] | 平价领导者 | [关键差异点] | [X]% |
| [品牌 B] | $[金额] | 中端 | [关键差异点] | [X]% |
| [品牌 C] | $[金额] | 高端 | [关键差异点] | [X]% |
| [品牌 D] | $[金额] | 性价比打法 | [关键差异点] | [X]% |

### 定价缺口分析

**识别到的市场机会：**

**1. 价格缺口：$[X] - $[Y]**
- **机会规模：** [市场潜力描述]
- **当前竞争：** [无/有限/中等]
- **客户需求：** [未满足的需求]
- **建议定位：** [策略建议]

**2. 功能-价格错配：[品类]**
- **当前市场：** [X 功能的产品卖 $Y]
- **机会：** [同价位更好功能，或同功能更低价格]
- **竞争优势：** [如何差异化]

**3. 高端缺口：$[X]+ 段**
- **现有供给：** [高端价位现有产品]
- **缺口：** [缺失的高端功能或定位]
- **市场规模：** [高端客群规模]

### 价格弹性洞察

**竞品定价行为模式：**

| 竞品 | 调价频率 | 促销策略 | 对竞争的响应 |
|------|---------|---------|-------------|
| [品牌 A] | [每周/每月] | [深折/买赠] | [激进/防御] |
| [品牌 B] | [季节性] | [捆绑] | [跟价] |
| [品牌 C] | [稳定] | [少量促销] | [高端定位] |

**市场价格敏感度分析：**
- **高弹性指标：** [价格战、频繁促销、利润承压]
- **低弹性客群：** [高端品牌、独特功能、强忠诚度]
- **价格阈值点：** $[金额]（平价上限）、$[金额]（高端下限）

### 战略性定价建议

**即时机会：**
1. **目标价位点：$[金额]**
   - **依据：** [缺口分析与竞争优势]
   - **定位：** [如何对位竞品]
   - **预期成果：** [份额与利润预测]

2. **竞争响应策略：**
   - **若[竞品]降价：** [建议响应]
   - **若进入高端段：** [定位与定价策略]
   - **季节性调整：** [节日与促销时机]

**长期定价策略：**
- **动态定价方法：** [何时调价、怎么调]
- **捆绑定价机会：** [交叉销售与增购策略]
- **价值定价：** [应突出的功能与利益]
- **市场扩张：** [可考虑的新价位段]

### 竞争监控框架

**要跟踪的关键指标：**
- **每日：** 前 5 竞品价格变动
- **每周：** 各价位段份额变化
- **每月：** 新进入者定价策略
- **每季：** 整体市场定价趋势

**价格警报阈值：**
- **激进竞争：** 主要竞品降价 >10%
- **市场机会：** $[X]-$[Y] 区间出现新缺口
- **高端位移：** $[Z] 以上出现新高端玩家

### 风险评估与缓解

**识别到的定价风险：**
- **逐底竞争风险：** [高/中/低] - [缓解策略]
- **高端挤压：** [被夹在性价比与高端之间的风险]
- **新进入者颠覆：** [概率与影响评估]

**建议的保障措施：**
- **最低可行利润率：** [X]% 以维持盈利
- **竞争响应预算：** [X]% 用于防御性定价
- **价值差异化：** [要建立的非价格竞争优势]

### 实施时间线

**阶段 1（即时 - 2 周）：**
- [ ] 对[具体产品]实施建议定价
- [ ] 搭建竞品价格监控警报
- [ ] 为新价格定位准备话术

**阶段 2（第 1–2 月）：**
- [ ] 围绕价值主张启动营销活动
- [ ] 监控市场反应与竞品动作
- [ ] 依初始反馈调整定价

**阶段 3（第 3 月起）：**
- [ ] 评估定价策略效果
- [ ] 把成功打法推广到更多产品
- [ ] 建设高级动态定价能力

### ROI 预测

**预期业务影响：**
- **收入增长：** 最优定价带来 [X]%
- **利润率改善：** [X] 个百分点
- **目标客群份额：** 增长 [X]%
- **竞争差异化：** [在 X 个细分建立更强定位]

### 下一步行动
- [ ] 基于分析敲定目标定价策略
- [ ] 搭建竞争价格监控系统
- [ ] 制作价值话术与定位物料
- [ ] 建立定价调整规程与决策框架
- [ ] 确立定期竞争定价复盘节奏
```
