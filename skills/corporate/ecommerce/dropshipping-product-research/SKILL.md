# Dropshipping 选品调研 📦

面向代发货（dropshipping）业务的选品调研。识别有可靠供应商、健康利润率与竞争可控的盈利产品。评估物流时效、退货风险与营销可行性。

**支持平台：** Amazon、Shopify、WooCommerce、Walmart、TikTok Shop、Etsy、eBay、BigCommerce。

由 [Nexscope](https://www.nexscope.ai/?co-from=skill) 构建，更聪明电商决策的 AI 助手。

## 安装

```bash
npx skills add nexscope-ai/eCommerce-Skills --skill dropshipping-product-research -g
```

## 用法

```
帮我在宠物用品细分市场找 dropshipping 产品。起步预算 2000 美元。我想通过 Shopify 销售、投 Meta 广告。
```

## 能力

- Dropshipping 产品可行性打分（利润率、重量、易碎性、退货风险）
- 供应商可靠性评估框架
- 按发货地/目的地分析物流时效与成本
- 营销角度识别（社交媒体、付费广告、SEO）
- 针对代发货细分市场的竞争分析
- 趋势验证与生命周期评估

## 本 Skill 如何工作

**第 1 步：** 从用户消息中收集信息，产品、平台、现状与目标。

**第 2 步：** 用选择题格式一次性追问所有剩余问题。允许简答（如 "1b 2c 3a"）。

**第 3 步：** 用下面的框架与方法论做调研分析。

**第 4 步：** 交付结构化、可执行的输出与具体建议，不给空泛建议。

## 输出格式

- 以发现摘要开头
- 尽可能给出具体数据点与基准
- 提供按优先级排序的行动项
- 基于不完整数据的估计标注 ⚠️
- 以具体的下一步收尾
