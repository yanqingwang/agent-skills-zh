# Serenity 方法来源

审阅日期：2026-09-14

Serenity.skill 的灵感来自与 [Serenity / @aleabitoreddit](https://x.com/aleabitoreddit) 相关的公开供应链研究。本项目是独立项目，不代表该账号所有者的背书。

## 方法背后的公开材料

[u/AleaBito 发布的 AXT/InP 供应链讨论](https://www.reddit.com/r/wallstreetbets/comments/1pyghud/the_entire_ai_buildout_google_nvda_msft_is/)把一条 AI/光子学论断向上游追溯到材料与衬底供应商。作者在讨论中还链接了[这条 X 帖子](https://x.com/aleabitoreddit/status/2004569946492453003)。审阅时 Reddit 原文可以访问；X 在本次审阅中无法直接取回。

那场讨论中可见的有用研究动作：

- 把宽泛的技术主题拆成所需的物理投入要素；
- 向更上游考察供应商集中度与扩产难度；
- 把技术约束与公司暴露、市场预期联系起来；
- 考虑可能中断论断的竞争技术与限制因素。

以上是对一条公开推理链的观察。帖子中的公司、市场份额与估值论断，需要各自的公司或行业证据；复述帖子并不能确立它们。

## 本项目的贡献

本 Skill 把这套研究模式变成普通投资研究可复用的流程，包含 A 股来源路径、明确的商业化阶段、针对论断的证据、盈利归因、估值日期，以及会改变判断的条件。

[AI 半导体案例](../examples/a-share-ai-semiconductor-demo.md)与 [CPO 公司论断挑战](../examples/cpo-company-challenge.md)是本项目对该方法的应用。它们的结论属于各自标注的研究日期，不属于该公开账号。

本页面用于署名归属。确立投资事实，请用公司披露文件、具名交易对手与技术来源。
