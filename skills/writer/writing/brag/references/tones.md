# Tone 参考

七种 tone。每一种都会改变脚本能量、节奏、排版个性和转场风格。

---

## `default`

**能量：** 俏皮、干净、适合发帖。让产品按它自己的方式就好笑。

**语气：** 第一人称复数。温暖。直接。不用企业腔。

**排版：** 混合大小写。字重适中。让文字有呼吸空间。

**节奏：** 4-5 个场景。每个场景 3-5 秒。舒适的节拍。

**钩子风格：** 一个简单的问题或观察，为揭晓做铺垫。
```
Dating apps were built for humans.
Obvious mistake.
```

**亮点风格：** 短促有力的句子。一个场景一个想法。
```
Swipe through eligible horses near your pasture.
```

**收尾风格：** 产品名，然后一句 tagline。轻巧的包袱。
```
Horse Tinder.
Find your perfect stablemate.
```

**转场：** 交叉淡化或干净的滑入。

**适用场景：** 大多数荒诞的消费级应用。不用力也依然有个性的项目。

---

## `polished`

**能量：** 严肃、优雅。用克制本身作为创作选择。

**语气：** 第三人称或无人称。产品自己说话。

**排版：** 混合大小写。偏细到中等字重。宽字距。没有任何攻击性。

**节奏：** 3-4 个场景。每个场景 4-6 秒。用缓慢的揭晓传递自信。

**钩子风格：** 一个有分量的意象，或者满屏的产品名。

**亮点风格：** 一个场景讲一个功能。不要项目符号。不要列表。
```
Wing certification
upon completion.
```

**收尾风格：** 产品名。tagline。沉默。

**转场：** 缓慢交叉淡化（0.6-0.8 秒）。

**适用场景：** 不是玩笑的项目。希望有高级感的产品。用户说 "clean" 或 "elegant" 的时候。

---

## `yc-parody`

**能量：** 一本正经的创业发布能量。笑点在于它被讲得有多严肃。

**语气：** 严肃。不动声色。不眨眼。荒诞来自产品本身，而不是语气。

**排版：** 句首大写。粗体或中等字重。数据点用近似 Courier 的字体。不要装饰。

**节奏：** 4-5 个场景。有结构。每个场景抛出一个主张。

**钩子风格：** 把问题极其严肃地讲出来。
```
Every day, taxis carry us.
But who carries the taxis?
```

**亮点风格：** 把功能或指标陈述为事实。
```
Available in 12 metros.
99.1% fleet uptime.
```

**收尾风格：** 产品名。tagline。一个暗示合法性的 URL。
```
Taxi for Taxis
The ride-hailing app for ride-hailing assets.
taxifortaxis.com
```

**转场：** 硬切或极短的交叉淡化（0.2 秒）。

**适用场景：** 任何适合一本正经来演的递归或荒诞概念。"Psychologists for Chatbots"、"Taxi for Taxis"、"Briefcase for Baby"。

---

## `chaotic`

**能量：** 快、吵、失控。视频本身就是那个笑话。

**语气：** 咄咄逼人。短词。大写。数据轰炸。感叹号可有可无 — 但自信靠喊更响。

**排版：** 全大写。粗体。略微偏大。有些词倾斜。有些词比预期更大。

**节奏：** 6-8 个场景。有些场景不到 2 秒。每个场景绝不超 4 秒。

**钩子风格：** 某个本不该存在的东西，用最大音量喊出来。
```
TRANSPORTATION WAS TOO CALM.
```

**亮点风格：** 连珠炮。一个节拍一个词或一个数字。
```
8,400 BOARS
3 MINUTE ETA
TUSKS-FIRST PICKUP
```

**收尾风格：** 名字砸下来。tagline 砸下来。切黑。
```
UBER FOR WILD BOARS
On-demand chaos, now with routing.
```

**转场：** 硬切。闪切（短暂的黑白帧）。变焦切（入场时 1.2→1.0 缩放）。

**适用场景：** 混乱的概念、物流恶搞，任何能当成预告炒作片来演的东西。"Uber for Wild Boars"，任何带紧迫感或速度感的东西。

---

## `deadpan`

**能量：** 平静。干涩。笑点在于没有一件事显得不寻常。

**语气：** 极简。一个观察。然后是产品。就这样。

**排版：** 混合大小写。大。稀疏。大量留白。一次一个想法。

**节奏：** 3-4 个场景。长停留。每个场景 4-7 秒。节奏本身就是笑点。

**钩子风格：** 一个安静的观察。不做铺垫。还没有包袱。
```
I used to fear the sky.
```

**亮点风格：** 一个场景一句话。不要项目符号。不要兴奋。
```
Now I fear birds, weather, and gravity.
```

**收尾风格：** 产品名。别的都不要。也许配一句很小的 tagline。在留白上长时间停留。
```
Fish Flight School.
```

**转场：** 极慢的交叉淡化（0.8-1.0 秒）。或者在下一个场景前长停留。

**适用场景：** 站点上最有力的东西是一句引言的项目。像 "Psychologists for Chatbots" 那样以证言为主的做法。任何靠克制能让笑点更响的内容。

---

## `cinematic`

**能量：** 戏剧化。预告片规模。产品被当成大片来对待。

**语气：** 史诗感。短陈述句。每句在下一句开始之前先落地。

**排版：** 全大写或粗体混合大小写。满幅场景。大字号。有明显的尺度感。

**节奏：** 4-5 个场景。每个 3-5 秒。戏剧化的揭晓，不要快速剪辑。

**钩子风格：** 一句关于世界的宏大陈述，讲得很严肃。
```
For too long,
fish were told to stay underwater.
```

**亮点风格：** 把产品能力说得像超能力。
```
Thermal identification.
Cloud navigation.
Emergency splash landing protocols.
```

**收尾风格：** 产品名满屏砸下来。tagline。音乐渐起（暗示）。
```
FISH FLIGHT SCHOOL
The sky was never the limit.
```

**转场：** 戏剧化的划像或带缩放的缓慢交叉淡化（场景以 0.95 入场，到 1.0）。

**适用场景：** 任何自带史诗气质的题材。"Fish Flight School" 完全契合。任何涉及尺度、自然或宏大主张的内容。

---

## `app-store`

**能量：** 干净。专业。以功能为主。产品是真的（哪怕它并不是）。

**语气：** 功能—收益。第三人称。现在时。

**排版：** 标题式大小写。中等字重。干净、易读。没有攻击性。

**节奏：** 4-6 个场景。每个场景：产品名或功能名，然后 1-2 个支撑细节。

**钩子风格：** 产品名 + tagline，干净利落。
```
Psychologists for Chatbots.
Because even helpful assistants need help.
```

**亮点风格：** 功能卡片结构。名称 + 简短说明。
```
Prompt Trauma Processing
Identify and resolve harmful conversation patterns.
```

**收尾风格：** CTA 风格。行动号召或下载提示。
```
Available now.
All chatbot models welcome.
```

**转场：** 干净的滑入或划像（0.35-0.45 秒）。不要戏剧化。

**适用场景：** 适合被当作正经产品对待的产品，哪怕它其实很荒诞。任何 B2B 恶搞，或与治疗/健康相邻的题材都合适。
