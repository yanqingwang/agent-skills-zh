# CIP 设计风格指南

## 企业极简（Corporate Minimal）
**行业：** 金融、法律、咨询、科技
**颜色：** 藏青（#0F172A）、白色（#FFFFFF）、蓝色点缀
**字体：** 简洁无衬线体（Inter、Helvetica）
**材质：** 高级哑光纸、细腻纹理
**表面工艺：** 哑光、Logo 局部 UV

## 现代科技（Modern Tech）
**行业：** 科技、SaaS、初创公司、AI
**颜色：** 紫色（#6366F1）、青色（#0EA5E9）、绿色（#10B981）
**字体：** 几何无衬线体（Outfit、Poppins）
**材质：** 光滑表面、渐变印刷
**表面工艺：** 亮光、金属点缀

## 奢华高端（Luxury Premium）
**行业：** 时尚、珠宝、酒店、精致餐饮
**颜色：** 黑色（#1C1917）、金色（#D4AF37）、白色
**字体：** 优雅衬线体（Playfair）、细无衬线体
**材质：** 厚实棉质纸、皮革、金属
**表面工艺：** 烫金、压凸、压凹、软触感

## 经典传统（Classic Traditional）
**行业：** 律所、传承型品牌、金融
**颜色：** 藏青、酒红、金色
**字体：** 传统衬线体（Times、Garamond）
**材质：** 优质纹理纸、木材
**表面工艺：** 凸版印刷、金色压凸

## 温暖自然（Warm Organic）
**行业：** 食品、有机产品、健康养生、手工艺
**颜色：** 棕色（#8B4513）、绿色（#228B22）、奶油色
**字体：** 亲和衬线体、自然手写体
**材质：** 牛皮纸、再生材料
**表面工艺：** 未涂布、天然纹理

## 大胆动感（Bold Dynamic）
**行业：** 体育、娱乐、游戏
**颜色：** 红色（#DC2626）、橙色（#F97316）、黑色
**字体：** 粗壮窄体无衬线
**材质：** 高对比、金属质感
**表面工艺：** 亮光、鲜艳色彩

## 清新现代（Fresh Modern）
**行业：** 医疗健康、养生、金融科技
**颜色：** 薄荷绿（#10B981）、天蓝（#0EA5E9）、白色
**字体：** 现代圆角无衬线
**材质：** 轻盈、干净的表面
**表面工艺：** 哑光、干净极简

## 柔美优雅（Soft Elegant）
**行业：** 美妆、婚礼、SPA、时尚
**颜色：** 粉色（#F472B6）、金色、白色
**字体：** 优雅手写体、细无衬线体
**材质：** 软触感、优质纸张
**表面工艺：** 玫瑰金烫金、压凸

## 色彩心理学

| 颜色 | 含义 | 最佳用途 |
|-------|---------|----------|
| 蓝色 | 信任、稳定 | 金融、科技、医疗健康 |
| 绿色 | 成长、自然 | 环保、养生、有机 |
| 金色 | 奢华、尊贵 | 高端、珠宝 |
| 红色 | 活力、激情 | 食品、体育 |
| 黑色 | 品质感 | 奢侈品、时尚 |
| 白色 | 干净、极简 | 科技、医疗健康 |
