## 22 种艺术方向风格

1. **极简（Minimalist）**：留白主导，单一焦点元素，1-2 种颜色，干净的无衬线体
2. **大字排印（Bold Typography）**：字排就是设计；超大、有表现力的字形铺满画布
3. **渐变 / 色洗（Gradient / Color Wash）**：平滑过渡、网格渐变、色相交融
4. **照片主导（Photo-Based）**：出血照片压文字；hero 级生活方式影像
5. **插画 / 手绘（Illustrated / Hand-Drawn）**：定制插画、专属图标、手作感
6. **几何 / 抽象（Geometric / Abstract）**：形状、线条、网格作为主要视觉元素
7. **复古（Retro / Vintage）**：做旧纹理、灰调色板、衬线字、半调网点
8. **玻璃拟态（Glassmorphism）**：磨砂玻璃面板、模糊背景、微光描边
9. **3D / 雕塑感（3D / Sculptural）**：渲染物体、纵深、阴影；以产品为中心
10. **霓虹 / 赛博朋克（Neon / Cyberpunk）**：深色背景、发光霓虹点缀、高对比
11. **双色调（Duotone）**：双色照片处理；品牌色大面积压图
12. **编辑 / 杂志风（Editorial / Magazine）**：重网格版式、引文提行、新闻式构图
13. **拼贴 / 混合媒介（Collage / Mixed Media）**：剪纸纹理、照片剪块、层叠元素
14. **复古未来主义（Retro Futurism）**：太空时代怀旧、铬金属、渐变、乐观主义
15. **表现主义 / 反设计（Expressive / Anti-Design）**：混乱版式、混搭字体、故意的"错误"构图
16. **数码可爱 / 卡哇伊（Digi-Cute / Kawaii）**：圆角形状、粉彩渐变、像素画、俏皮角色
17. **触感 / 感官（Tactile / Sensory）**：蓬松/软弹纹理、超现实材质、压凹感
18. **数据 / 信息图（Data / Infographic）**：统计数字站 C 位、图表、数字当主角
19. **暗色 / 情绪化（Dark Mode / Moody）**：近黑背景、浓郁宝石色、高对比
20. **平面 / 纯色（Flat / Solid Color）**：单一背景色、干净图标、无渐变
21. **自然 / 有机（Nature / Organic）**：大地色系、植物纹样、可持续品牌感
22. **动效就绪 / 动态（Motion-Ready / Kinetic）**：为动画而设计；分层元素、可循环

## 设计原则

### 视觉层级（三区法则）
- **上**：Logo 或主要价值主张
- **中**：支撑信息 + 视觉
- **下**：CTA（按钮/二维码/URL）

### 安全区
- 关键内容放在画布中央 70-80%
- 文字/CTA 避开距边缘 50-100px 的范围
- YouTube：2560 × 1440 里留 1546 × 423px 安全区
- Meta/Instagram：中央 80%，避开 UI chrome

### CTA 规则
- 每条横幅一个 CTA
- 与背景高对比
- 右下放置（收尾区）
- 移动端点按目标最小 44px 高
- 行动动词："Get"、"Start"、"Download"、"Claim"

### 字排
- 每条横幅最多 2 种字体
- 正文最小 16px，标题 >=32px（数字端）
- 对比度最小 4.5:1
- 每行最多 7 个词，广告最多 3 行

### 文字与图像比例
- 广告：文字低于 20%（Meta 会惩罚）
- 社交封面：图与文 60/40
- 印刷：3-5 米观看距离用 70pt 以上的标题

### 印刷规格
- 最低 300 DPI（大幅面 150 DPI）
- 四边出血 3-5mm
- CMYK 色彩模式
- 每 1 英尺观看距离对应 1pt 的经验法则
