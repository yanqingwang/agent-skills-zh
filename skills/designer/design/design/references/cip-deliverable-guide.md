# CIP 交付物指南

## 核心识别

### 主标志
- 矢量格式（SVG、AI、EPS）
- 已定义净空规则
- 从网站图标到广告牌均可缩放

### 标志变体
- 横版、竖版、堆叠
- 仅图标/符号
- 单色版本（黑、白、反白）

## 文具套装

### 名片
- 标准规格：3.5x2 英寸 / 85x55mm
- 高级纸料（300-400gsm）
- 表面工艺：哑光、局部 UV、烫金、压纹

### 信纸信头
- A4 或 Letter 尺寸
- 页眉区域放标志/联系方式
- 电子版与印刷版

### 信封
- DL、C4、C5 尺寸
- 标志在封口或正面
- 回信地址样式

## 办公环境

### 前台标识
- 3D 立体字
- 背光 LED 选项
- 材质：亚克力、金属、木质

### 导视系统
- 图标体系统一
- 层级清晰
- 符合 ADA（美国残障法案）规范

### 墙面图形
- 使命/价值观展示
- 大幅壁画
- 玻璃磨砂贴膜

## 服装

### Polo 衫
- 优先刺绣
- 左胸位置
- 优质面料（珠地棉）

### 工装制服
- 部门颜色区分
- 姓名牌集成
- 如适用，满足安全要求

## 车辆品牌化

### 轿车
- 车门板品牌化
- 局部或整车贴膜
- 联系方式可见

### 车队车辆
- 全车队设计一致
- 联系方式高可见度
- 专业安装

## 数字资产

### 社交媒体
- 头像图（图标版）
- 封面图（按平台定制）
- 帖子模板

### 邮件签名
- HTML 响应式
- 最大 600px 宽
- 只放必要联系方式

## 活动与宣传

### 展会展台
- 模块化设计
- 易于搭建
- 关键信息可见

### 宣传品
- 重质不重量
- 优先选实用的物品
- 品牌色醒目
