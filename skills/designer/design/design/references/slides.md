# Slides 参考

策略化的 HTML 演示文稿设计：Chart.js 数据可视化、design tokens、响应式布局与文案公式。

## 用法

激活 `design` Skill 并指明幻灯片任务，例如 "create a pitch deck"（做一份路演稿）。

## 知识库

| 主题 | 文件 | 用途 |
|-------|------|---------|
| 创建指南 | `references/slides-create.md` | 分步幻灯片创建工作流 |
| 版式模式 | `references/slides-layout-patterns.md` | 幻灯片版式模板与网格体系 |
| HTML 模板 | `references/slides-html-template.md` | 演示文稿的基础 HTML 结构 |
| 文案 | `references/slides-copywriting-formulas.md` | 用于幻灯片内容的 AIDA、PAS、FAB |
| 策略 | `references/slides-strategies.md` | 按演示类型划分的情境化策略 |

## 何时使用

- 营销演示与融资路演稿
- 带 Chart.js 可视化的数据幻灯片
- 用版式模式做策略化幻灯片设计
- 文案公式优化的演示内容
- 投资人 deck、销售演示、团队汇报

## 关键特性

- **Chart.js 集成**：柱状图、折线图、饼图、环形图、雷达图
- **Design Tokens**：一致的间距、颜色、字体
- **响应式**：桌面与移动端均可用
- **文案**：内置 AIDA、PAS、FAB 公式
- **版式模式**：Hero、分栏、网格、对比、时间线

## 工作流

1. 从用户请求解析演示类型
2. 加载 `references/slides-create.md` 获取创建指南
3. 从 `references/slides-layout-patterns.md` 选择版式模式
4. 应用 `references/slides-copywriting-formulas.md` 的文案公式
5. 使用 `references/slides-html-template.md` 的 HTML 模板
6. 应用 `references/slides-strategies.md` 的策略
