# Logo Style Guide

## 核心 Logo 类型

### 1. 字标（Wordmark / Logotype）
只用定制字体排印的文字 Logo。
- **适用：**已成型的品牌、名字有辨识度的品牌
- **示例：**Google、Coca-Cola、FedEx
- **字体：**定制字形、独特字距
- **要点：**名字必须好记且好念

### 2. 字母标（Lettermark / Monogram）
首字母或缩写字母。
- **适用：**名称很长的公司、专业事务所
- **示例：**IBM、HBO、NASA
- **字体：**粗壮的几何无衬线体
- **要点：**适合有 2-4 个字母缩写的品牌

### 3. 图形标（Pictorial Mark / Brand Mark）
独立的图标或符号。
- **适用：**已有认知度的全球品牌
- **示例：**Apple、Twitter、Target
- **设计：**简单、可缩放、好记的形状
- **要点：**需要品牌资产积累才能单独成立

### 4. 抽象标（Abstract Mark）
非具象的几何形状。
- **适用：**科技公司、需要差异化的品牌
- **示例：**Pepsi、Airbnb、Spotify
- **设计：**用独特形状传达品牌价值
- **要点：**能把复杂理念表达得简单

### 5. 吉祥物（Mascot）
代表品牌的角色形象。
- **适用：**家庭品牌、运动队、食品
- **示例：**KFC、Pringles、Michelin
- **设计：**亲和、有表现力、用途多样
- **要点：**品牌演进时仍能保持辨识度

### 6. 徽章（Emblem）
包在形状之内的符号。
- **适用：**传统品牌、组织机构
- **示例：**Starbucks、Harley-Davidson、NFL
- **设计：**徽章、印章或纹章风格
- **要点：**缩小使用时可能有困难

### 7. 组合标（Combination Mark）
图标 + 文字的一体化设计。
- **适用：**新品牌、多场景应用
- **示例：**Burger King、Lacoste、Doritos
- **设计：**组合方式灵活的 lockup
- **要点：**用途最广，日后可拆开使用

## 美学风格

### 极简（Minimalist）
- 干净的线条，只留必要元素
- 大量留白，简单几何
- 有限的配色（1-2 种颜色）
- **适用：**科技、专业服务、现代品牌

### 复古/怀旧（Vintage/Retro）
- 怀旧、有年代感
- 做旧纹理、低饱和色彩
- 手写体或粗衬线体
- **适用：**手工品牌、匠人产品

### 奢华/高端（Luxury/Premium）
- 优雅、精致的观感
- 金、黑、白配色
- 细衬线或考究的无衬线体
- **适用：**时尚、珠宝、高端服务

### 几何（Geometric）
- 数学般的精确
- 圆、三角、方
- 完美对称
- **适用：**建筑、科技、现代品牌

### 有机/自然（Organic/Natural）
- 流动、不完美的线条
- 大地色、自然色
- 手绘感
- **适用：**环保品牌、健康、有机产品

### 渐变/现代（Gradient/Modern）
- 颜色过渡、鲜艳配色
- 纵深层次
- 当代感
- **适用：**应用、科技初创、数字产品

## 风格选择矩阵

| 品牌类型 | 首选风格 | 备选风格 |
|------------|---------------|-------------------|
| 科技初创 | 极简、抽象 | 几何、渐变 |
| 律所 | 字标、徽章 | 字母标 |
| 餐厅 | 吉祥物、徽章 | 复古、组合标 |
| 时尚 | 字标、奢华 | 字母标、线稿 |
| 医疗 | 专业、线稿 | 抽象、组合标 |
| 非营利组织 | 组合标、徽章 | 有机、手绘 |

## 可缩放性检查清单

- [ ] 在 16x16 像素（favicon）下仍可辨认
- [ ] 在名片尺寸下清晰
- [ ] 单色可用
- [ ] 黑白显示下保持清晰
- [ ] 没有缩放后会消失的微小细节
