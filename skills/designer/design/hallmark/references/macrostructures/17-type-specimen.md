## 17 · Type Specimen

字体就是设计。字厂页面和以定制字体为证据的设计体系。

- **标题：** 该字体以多个字号排布，演示它能做什么。
- **正文：** 递进式的演示：展示字号、正文字号、斜体、语言覆盖、OpenType 特性。
- **分隔：** 每份样本之下一个 `<figcaption>`；图注在下方合法，标签在上方就是 eyebrow（54）。
- **按钮：** 首屏内一个描边动作（"Buy the family"，买下整个字族）（44b），在页脚回访。
- **图像：** 不放；字体排印就是图像。
- **Reveal：** 一次文字揭幕，用在第一份样本落纸之时；其余的就那么摆着。

字厂、以定制字体为差异点的设计体系、字体产品页选它。

品牌用的是现成字体时避免使用。Type Specimen 需要值得称颂的独特之物。

**样例开篇句**（字厂语气：点名字面、字重、用途）：
> *"Corvid Display, set at 96pt."*（Corvid Display，96pt 排布。）点名字面与字号，没有别的。
> *"Eight weights. Three optical sizes. One good italic."*（八个字重。三个光学字号。一款好斜体。）三个短语清点体系。
> *"A type system for editorial."*（一套给编辑体的字体系统。）拒绝动词，一个名词短语。
