# Banner Design - 多格式创意横幅系统

跨社交媒体、广告、Web 与印刷格式设计横幅。生成多个艺术方向方案，视觉元素可由 CSS 构建、用户提供，或（可选）由生成式能力产出。本 Skill 仅负责横幅设计，不负责视频剪辑、完整网站设计或印刷生产。

## 何时应用

- 用户请求横幅、封面或页头设计
- 社交媒体封面/页头制作
- 广告横幅或展示广告设计
- 网站 Hero 区视觉设计
- 活动/印刷横幅设计
- 为营销活动生成创意素材

## 可用资源

本工作流自包含：不依赖同级 Skill 或 Skill 相对路径的脚本。尺寸、安全区与艺术方向指引见内置的 `references/banner-sizes-and-styles.md`。浏览器调研、图像生成与截图工具均为可选能力；不可用时，改用已提供的素材、CSS 构建的视觉元素，以及运行时的标准预览或截图流程。

## 工作流

### 第 1 步：收集需求（AskUserQuestion）

通过 AskUserQuestion 收集：
1. **用途** — 社交封面、广告横幅、网站 Hero、印刷品，还是创意素材？
2. **平台/尺寸** — 哪个平台，还是自定义尺寸？
3. **内容** — 主标题、副文案、CTA、logo 位置？
4. **品牌** — 既有品牌规范、logo 文件、色彩或字体排印？
5. **风格偏好** — 有无艺术方向倾向？（拿不准时展示风格选项）
6. **数量** — 生成几个方案？（默认：3）

### 第 2 步：调研与艺术方向

1. 阅读 `references/banner-sizes-and-styles.md`，了解目标格式、安全区与合适的风格。
2. 若浏览器调研可用且获准使用，收集 3–5 个参考案例作为构图与艺术方向灵感；否则基于内置参考与用户提供的示例开展工作。
3. 选出 2–3 个互补的艺术方向，并说明各自如何支撑横幅的用途。

### 第 3 步：设计与生成方案

对每个艺术方向方案：

1. **用 HTML/CSS 制作横幅**
   - 使用尺寸参考中的精确平台尺寸
   - 遵守安全区规则（关键内容置于中央 70–80% 区域）
   - 至多使用 2 种字体、单一 CTA，文字对比度不低于 4.5:1
   - 应用用户提供的 logo、色彩、字体排印与图像素材；不得凭空捏造品牌规则

2. **选择视觉素材来源**
   - 用户已提供素材时，优先使用用户提供的或授权合规的素材
   - 使用渐变、几何形体、文字及其他 CSS 构建的视觉元素，实现零依赖的效果
   - 若运行时提供经授权的图像生成能力，可按目标宽高比生成背景或插画
   - 生成视觉画面的提示词中不要包含文本、字母或文字，以确保最终文案在 HTML 中保持可编辑且无障碍

3. **合成最终横幅** — 在 HTML/CSS 中叠加主标题、辅助文案、CTA 与 logo，然后在精确目标尺寸下核验层级、安全区、对比度与裁切表现

### 第 4 步：将横幅导出为图片

完成 HTML 横幅设计后：

1. 在可用的浏览器中以精确目标视口预览每张横幅。
2. 使用运行时标准的浏览器或截图能力，将横幅元素截取为 PNG。若截图能力不可用，则交付 HTML/CSS 源码并明确标注 PNG 导出尚待完成，而不是编造一个未安装的工具名。
3. 核验导出的像素尺寸、安全区裁切、字体加载与图像质量。
4. 若导出文件超出平台限制，使用可用的图片优化工具，或在平台规格允许范围内降低图像质量与尺寸。

**输出路径约定：**
```
assets/banners/{campaign}/
├── minimalist-1500x500.png
├── gradient-1500x500.png
├── bold-type-1500x500.png
├── minimalist-1080x1080.png    # if multi-size requested
└── ...
```

- 文件名使用 kebab-case：`{style}-{width}x{height}.{ext}`
- 有时效性的活动加日期前缀：`{YYMMDD}-{style}-{size}.png`
- 活动文件夹将所有变体归拢在一起

### 第 5 步：展示方案并迭代

并排展示所有导出的图片。每个方案需展示：
- 艺术方向风格名称
- 导出的 PNG 预览；截图不可用时提供 HTML/CSS 预览
- 关键设计理由
- 文件路径与尺寸

根据用户反馈迭代，直至获得认可。

## 艺术方向风格（前 10 种）

| 风格 | 最适合 | 关键元素 |
|------|--------|----------|
| 极简（Minimalist） | SaaS、科技 | 留白、1-2 种颜色、简洁字型 |
| 粗体排印（Bold Typography） | 公告 | 超大字号文字作为主视觉元素 |
| 渐变（Gradient） | 现代品牌 | 网状渐变、色彩交融 |
| 照片型（Photo-Based） | 生活方式、电商 | 满版照片 + 文字叠加 |
| 几何（Geometric） | 科技、金融科技 | 形状、网格、抽象图案 |
| 复古（Retro/Vintage） | 餐饮、手作 | 做旧纹理、低饱和配色 |
| 玻璃拟态（Glassmorphism） | SaaS、应用 | 磨砂玻璃、模糊、发光描边 |
| 霓虹/赛博朋克（Neon/Cyberpunk） | 游戏、活动 | 深色背景、发光霓虹点缀 |
| 编辑风（Editorial） | 媒体、奢侈品 | 网格布局、醒目引文 |
| 3D/雕塑感（3D/Sculptural） | 产品、科技 | 渲染物体、景深、阴影 |

全部 22 种风格：`references/banner-sizes-and-styles.md`

## 设计规则

- **安全区**：关键内容置于画布中央 70-80% 区域
- **CTA**：每张横幅一个，位于右下角，高度至少 44px，使用动作动词
- **字体排印**：最多 2 种字体，正文最小 16px，标题 ≥32px
- **文字占比**：广告中低于 20%（Meta 会惩罚文字过多的素材）
- **印刷**：300 DPI、CMYK、3-5mm 出血
- **品牌**：只应用已提供的、经验证的品牌指引与素材
