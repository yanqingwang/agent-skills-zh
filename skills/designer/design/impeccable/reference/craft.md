# Craft（已弃用别名）

`craft` 是"普通的新视觉作品请求"的已弃用别名。它不添加任何安装、访谈、检查点、工具或质量行为。按 SKILL.md 的正常路由走：缺 PRODUCT.md 时经 [init.md](init.md) 创建，然后遵循 [new-work.md](new-work.md) 处理视觉权威、世界与界面决策、实现与收尾。

不要告诉用户需要调用 `craft`。"build this feature"（做这个功能）、"make a landing page"（做一份落地页）或 "redesign this screen"（重设计这个屏幕）之类的自然请求走同一流程。
