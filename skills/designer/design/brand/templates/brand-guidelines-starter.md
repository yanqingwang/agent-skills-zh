## 3. Logo 使用

### 变体

| 变体 | 文件 | 使用场景 |
|---------|------|----------|
| 全横式 | logo-full-horizontal.svg | 页头、文档 |
| 竖排式 | logo-stacked.svg | 方形空间 |
| 仅图标 | logo-icon.svg | favicon、小空间 |
| 单色 | logo-mono.svg | 色彩受限场景 |

### 净空

最小净空 = logo 图标（标志图形）的高度

### 最小尺寸

| 场景 | 最小宽度 |
|---------|---------------|
| 数字端 - 完整 Logo | 120px |
| 数字端 - 图标 | 24px |
| 印刷 - 完整 Logo | 35mm |
| 印刷 - 图标 | 10mm |

### 禁止事项

- 不要旋转或倾斜 logo
- 不要使用批准色板之外的颜色
- 不要加阴影或特效
- 不要裁切或修改比例
- 不要放在对比度不足的花杂背景上

## 4. 语气与语调

### 品牌个性

| 特质 | 描述 |
|-------|-------------|
| **专业** | 专业知识扎实，权威而不失亲和 |
| **乐于助人** | 聚焦解决方案，指导可执行 |
| **清晰** | 直接表达，不用行话 |
| **自信** | 有把握而不傲慢 |

### 语气对照表

| 特质 | 我们是 | 我们不是 |
|-------|--------|------------|
| 专业 | 专家、有见识 | 刻板、官腔 |
| 乐于助人 | 支持、赋能 | 居高临下 |
| 清晰 | 直接、简洁 | 含糊、啰嗦 |
| 自信 | 有把握、可信 | 傲慢、过度推销 |

### 分场景语调

| 场景 | 语调 | 示例 |
|---------|------|---------|
| 营销 | 有感染力、聚焦收益 | “打造能带来转化的营销活动。” |
| 文档 | 清晰、指导性 | “运行命令以启动。” |
| 错误信息 | 平静、聚焦解决 | “试试刷新页面。” |
| 成功 | 简短、带庆祝感 | “营销活动已发布！” |

### 禁用词

| 禁用 | 原因 |
|-------|--------|
| Revolutionary | 用滥了 |
| Best-in-class | 含糊的宣称 |
| Seamless | 用滥了 |
| Synergy | 企业空话 |
| Leverage | 改用 “use” |

## 5. 图像指南

### 摄影风格

- **光线：**偏好自然、柔和的光线
- **主体：**真实人物、真实场景
- **色彩处理：**后期保持品牌色
- **构图：**干净、主体突出

### 插画

- 风格：现代、扁平设计，带细腻渐变
- 颜色：只用品牌色板
- 线宽：统一 2px 描边
- 圆角：4px

### 图标

- 风格：线框式，24px 基础网格
- 描边：统一 1.5px
- 圆角半径：2px
- 填充：无（仅线框）
