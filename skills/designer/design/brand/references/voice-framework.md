# 品牌声音框架

## 声音与语调

**声音（Voice）**= 品牌的个性（恒定）
**语调（Tone）**= 声音如何随语境调整（可变）

例：一个友好的品牌（声音）在喜讯公告里可以欢庆，在客服回复里则要有同理心（语调）。

## 声音维度

### 语调光谱

```

```


### 情绪光谱
```
Reserved ←――――――――――――――→ Expressive
[Corporate]      [Lifestyle brand]
```

## 声音开发流程

### Step 1: 定义个性特质
选 3-5 个描述品牌的特质：
- 自信，不傲慢
- 友好，不散漫
- 懂行，不居高临下
- 创新，不玩噱头
- 真实，不随意

### Step 2: 制作声音对照表

| 特质 | 说明 | 要做 | 不要做 |
|-------|-------------|-----|-------|
| [特质] | [含义] | [示例] | [示例] |

### Step 3: 语境适配

| 语境 | 语调调整 | 示例 |
|---------|------------|---------|
| 社交媒体 | 更随意 | "Hey there!" |
| 客服支持 | 更有同理心 | "We understand..." |
| 法律 | 更正式 | "In accordance with..." |
| 销售 | 更自信 | "You'll see results..." |

## 声音测试

问这些问题：
1. 这听起来像我们的品牌吗？
2. 竞争对手会这么说吗？
3. 我们的受众会共鸣吗？
4. 与我们的价值观一致吗？
