# 素材审批清单

在批准之前审查营销素材的综合清单。

## 快速审查

在详细审查之前，先确认：
- [ ] 素材服务于既定目的
- [ ] 目标受众合适
- [ ] 无明显错误或问题
- [ ] 与活动目标一致

## 视觉元素

### Logo 使用
- [ ] 针对场景选择了正确的 Logo 变体
- [ ] 保持了适当的净空区（clear space）
- [ ] 满足最小尺寸要求
- [ ] 仅使用已批准的颜色
- [ ] 无未经授权的修改
- [ ] 与背景搭配得当

### 颜色合规
- [ ] 仅使用品牌色板中的颜色
- [ ] 主色/辅色比例合适（60/30/10）
- [ ] 语义色使用正确
- [ ] 未引入品牌外的颜色
- [ ] 各元素之间保持一致

### 字体排印
- [ ] 全文使用品牌字体
- [ ] 应用了正确的字重
- [ ] 字体层级正确
- [ ] 尺寸适合该媒介
- [ ] 行高充足
- [ ] 正文无孤行/寡行（orphans/widows）

### 图像
- [ ] 符合品牌摄影风格
- [ ] 主题/内容合适
- [ ] 质量达到要求
- [ ] 已正确授权/署名
- [ ] 针对预期用途做了优化

## 可访问性

### 视觉可访问性
- [ ] 文本对比度 >= 4.5:1（AA）
- [ ] 大文本对比度 >= 3:1
- [ ] 交互元素有可见的焦点态
- [ ] 颜色不是传达含义的唯一手段
- [ ] 所有图片都有替代文本（alt text）

### 内容可访问性
- [ ] 布局清晰、易于扫读
- [ ] 字号可读
- [ ] 阅读顺序合乎逻辑
- [ ] 标题结构有意义
- [ ] 链接描述了目标位置

## 内容质量

### 文案审查
- [ ] 符合品牌语调
- [ ] 语气适合场景
- [ ] 未使用禁用词
- [ ] 价值主张清晰
- [ ] CTA 有吸引力且明确
- [ ] 已校对错误

### 信息传达
- [ ] 与关键信息一致
- [ ] 突出了差异化优势
- [ ] 强调收益而非功能
- [ ] 面向目标受众
- [ ] 无相互冲突的说法

## 技术要求

### 文件规格
- [ ] 文件格式正确
- [ ] 分辨率合适
- [ ] 文件体积已优化
- [ ] 命名符合规范
- [ ] 包含元数据

### 平台要求
| 平台 | 已验证 |
|----------|----------|
| Instagram | [ ] 尺寸正确 |
| Twitter/X | [ ] 满足要求 |
| LinkedIn | [ ] 达到专业标准 |
| Facebook | [ ] 符合指南 |
| Email | [ ] 体积小于 1MB |
| Web | [ ] 已为 Web 优化 |

## 法律与合规

### 知识产权
- [ ] 图库图片已获授权
- [ ] 音乐/音频已清理授权
- [ ] 无商标侵权
- [ ] 用户内容已获授权
- [ ] 需要署名的地方已署名

### 监管
- [ ] 包含必需的披露信息
- [ ] 无误导性说法
- [ ] 价格准确
- [ ] 需要的地方已链接条款
- [ ] 符合隐私要求

## 常见问题与修复

| 问题 | 修复 |
|-------|-----|
| Logo 过小 | 放大到最小尺寸 |
| 字体错误 | 换成品牌字体 |
| 对比度低 | 为可访问性调整颜色 |
| 品牌外颜色 | 换成色板内颜色 |
| 图片模糊 | 使用更高分辨率的源图 |
| 缺少替代文本 | 添加描述性 alt text |
| CTA 薄弱 | 强化行动导向的文案 |

## 自动化支持

`validate-asset.cjs` 脚本可自动检查：
- 颜色色板合规
- 最小尺寸
- 文件格式/体积
- 命名规范
- 基本元数据

运行：`node scripts/validate-asset.cjs <asset-path>`

## 归档

批准之后：
1. 在 manifest.json 中更新素材状态
2. 添加批准人和时间戳
3. 将旧版本移入 archive
4. 更新活动跟踪
5. 通知相关团队
