# 品牌一致性检查清单

## 视觉一致性

### 标志
- [ ] 使用了正确的标志版本
- [ ] 净空保持得当
- [ ] 只用已批准的颜色
- [ ] 所有尺寸下清晰可读
- [ ] 无未经批准的修改

### 颜色
- [ ] 只用品牌色板内的颜色
- [ ] 颜色用法一致
- [ ] 对比度满足无障碍要求
- [ ] 颜色比例保持不变

### 字体排印
- [ ] 使用品牌字体
- [ ] 字重/样式正确
- [ ] 层级得当
- [ ] 格式一致

### 图像
- [ ] 符合品牌风格
- [ ] 调色/滤镜一致
- [ ] 主题恰当
- [ ] 质量达标

## 语气一致性

### 语调
- [ ] 符合品牌个性
- [ ] 语境恰当
- [ ] 各渠道一致
- [ ] 无相互冲突的信息

### 用语
- [ ] 使用品牌术语
- [ ] 大小写规则一致
- [ ] 缩写规范
- [ ] 行话程度合适

### 信息传达
- [ ] 与关键信息一致
- [ ] 价值主张清晰
- [ ] 差异点突出
- [ ] 行动号召（CTA）一致

## 渠道审查

### 网站
- [ ] 首页
- [ ] 产品页
- [ ] 博客/内容
- [ ] 页脚/导航

### 社交媒体
- [ ] 头像图
- [ ] 封面图
- [ ] 简介/关于区块
- [ ] 帖子模板

### 邮件
- [ ] 页眉/页脚
- [ ] 模板
- [ ] 签名
- [ ] 自动消息

### 物料
- [ ] 演示文稿
- [ ] 单页介绍
- [ ] 名片
- [ ] 宣传材料

## 常见问题

| 问题 | 处理 |
|-------|-----|
| 标志过时 | 换成当前版本 |
| 颜色偏离品牌 | 更新为色板色 |
| 字体错误 | 换成品牌字体 |
| 语气不一致 | 按风格指南执行 |
| 信息混杂 | 向框架对齐 |

## 审查频率

| 资产类型 | 频率 |
|------------|-----------|
| 网站 | 每月 |
| 社交媒体资料 | 每季度 |
| 邮件模板 | 每季度 |
| 销售物料 | 每季度 |
| 全面品牌审查 | 每年 |
