# Logo 使用规范（Logo Usage Rules）

在所有营销物料中正确落地 logo 的指南。

## Logo 变体

### 主变体
| 变体 | 文件名 | 使用场景 |
|---------|-----------|----------|
| 完整横排 | logo-full-horizontal.{ext} | 网站页头、文档 |
| 竖排堆叠 | logo-stacked.{ext} | 方形空间、社交头像 |
| 仅图标 | logo-icon.{ext} | Favicon、应用图标、小空间 |
| 仅字标 | logo-wordmark.{ext} | 图标已在场时 |

### 颜色变体
| 变体 | 使用场景 |
|---------|----------|
| 全彩 | 白色/浅色背景上的默认选项 |
| 反白 | 深色背景上 |
| 深色单色 | 浅色背景且无法用彩色时 |
| 浅色单色 | 深色背景且无法用彩色时 |

## 留白（Clear Space）

### 最小留白
logo 周围的留白应等于 logo 图形（图标部分）的高度。

```
    ┌─────────────────────────────┐
    │           [x]               │
    │   ┌───────────────────┐     │
    │   │                   │     │
[x] │   │    [LOGO]         │ [x] │
    │   │                   │     │
    │   └───────────────────┘     │
    │           [x]               │
    └─────────────────────────────┘
```

其中 [x] = logo 图形的高度

## 最小尺寸

### 数字端
| 格式 | 最小宽度 | 说明 |
|--------|---------------|-------|
| 完整 logo | 120px | 所有元素清晰可辨 |
| 仅图标 | 24px | Favicon/小图标 |
| 仅图标 | 32px | UI 元素 |

### 印刷
| 格式 | 最小宽度 | 说明 |
|--------|---------------|-------|
| 完整 logo | 35mm | 名片、信纸 |
| 仅图标 | 10mm | 小型印刷品 |

## 颜色使用

### 批准使用的背景
| 背景 | logo 版本 |
|------------|--------------|
| 白色 | 全彩或深色单色 |
| 浅灰（#F5F5F5 以上） | 全彩或深色单色 |
| 品牌主色 | 反白（白色） |
| 深色（#333 或更深） | 反白（白色） |
| 照片 | 确保对比度充足 |

### 颜色规则
1. 绝不改用批准调色板之外的 logo 颜色
2. 不给 logo 用渐变
3. 不给 logo 元素加透明度
4. 不加阴影或特效

## 错误用法

### 绝对禁止
- ❌ 拉伸或压缩 logo
- ❌ 倾斜旋转
- ❌ 加投影
- ❌ 用渐变填充
- ❌ 用未批准的颜色
- ❌ 加描边或轮廓线
- ❌ 放在杂乱背景上
- ❌ 裁掉任何部分
- ❌ 重排元素
- ❌ 添加额外元素

### 图示示例
```
WRONG: Stretched      WRONG: Rotated       WRONG: Wrong color
┌──────────────┐      ┌────────┐          ┌────────┐
│   L O G O    │      │  /    │          │ LOGO   │ <- wrong color
└──────────────┘      │ /LOGO │          └────────┘
                      └───────/
```

## 联合品牌（Co-branding）

### 合作伙伴 logo 规范
1. 视觉分量相等（同高）
2. 两个 logo 之间间隔充分
3. 需要时用分隔线
4. 两个 logo 都用各自批准的颜色
5. 留白规则对两者都适用

### 排版选项
```
Option A: Side by side with divider
[OUR LOGO] | [PARTNER LOGO]

Option B: Stacked
    [OUR LOGO]
        +
  [PARTNER LOGO]
```

## 文件格式

### 推荐格式
| 用途 | 格式 | 说明 |
|-------|--------|-------|
| 网页 | SVG | 首选，可缩放 |
| 网页备选 | PNG | 带透明通道 |
| 印刷 | PDF | 矢量，高质量 |
| 印刷替代 | EPS | 老旧系统 |
| 文档 | PNG | 高分辨率（300dpi） |

### 文件组织
```
assets/logos/
├── full-horizontal/
│   ├── logo-full-color.svg
│   ├── logo-full-color.png
│   ├── logo-reversed.svg
│   ├── logo-mono-dark.svg
│   └── logo-mono-light.svg
├── icon-only/
│   ├── icon-full-color.svg
│   ├── icon-reversed.svg
│   └── favicon.ico
└── monochrome/
    ├── logo-black.svg
    └── logo-white.svg
```

## 平台专项指南

### 社交媒体
| 平台 | 格式 | 尺寸 | 说明 |
|----------|--------|------|-------|
| LinkedIn | PNG | 300x300px | 仅图标 |
| Twitter/X | PNG | 400x400px | 仅图标 |
| Facebook | PNG | 180x180px | 仅图标 |
| Instagram | PNG | 320x320px | 仅图标 |

### 网站
| 位置 | 变体 | 尺寸 |
|----------|---------|------|
| 页头 | 完整横排 | 宽 120-200px |
| 页脚 | 完整横排 | 宽 100-150px |
| Favicon | 仅图标 | 32x32px |
| Apple Touch | 仅图标 | 180x180px |

### 文档
| 文档 | 变体 | 摆放位置 |
|----------|---------|-----------|
| 信纸 | 完整横排 | 左上 |
| 演示文稿 | 图标 + 字标 | 标题页 |
| 报告 | 完整横排 | 封面 + 页脚 |

## Logo 审批流程

### 使用 logo 之前
1. 确认拿到的版本正确
2. 检查背景兼容性
3. 确认满足最小尺寸要求
4. 确认留白分配
5. 对照本指南复查

### 申请批准
非标准用途：
1. 提交展示拟用法的效果图
2. 附上语境（媒介、受众）
3. 等品牌团队批准
4. 把批准的例外写成文档
