# Canvas 设计系统

视觉设计哲学、系统化构图与精致的视觉传达。

## 设计哲学方法论

Canvas 设计通过两阶段流程运作：

### Phase 1: 创建设计哲学

创造视觉哲学：通过形式、空间、色彩与构图表达的美学流派。不是版式或模板，而是纯粹的视觉哲学。

**产出物：**一份设计宣言，强调：
- 视觉表达优先于文字
- 空间传达
- 艺术诠释
- 极少的文字作为视觉点缀

**哲学结构（4-6 段）：**
- 空间与形式原则
- 色彩与材质取向
- 尺度与节奏指引
- 构图与平衡规则
- 视觉层级系统

### Phase 2: 视觉表达

通过 canvas 作品表达哲学：
- 90% 视觉设计
- 10% 必要文字
- 博物馆级完成度
- 系统化图案
- 精致构图

## 核心原则

### 1. 视觉传达优先

信息存在于设计里，不在段落里。通过以下方式表达想法：
- 色彩区域与色块
- 几何精度
- 空间关系
- 视觉重量与张力
- 形式与结构

### 2. 极简文字融入

文字是稀有而有力的手势：
- 绝不用段落
- 只用必要的词
- 融入视觉架构
- 小标签，大冲击
- 字体排印本身就是视觉元素

### 3. 专家级工艺

作品必须显得：
- 经过精心打磨
- 被用心雕琢过
- 是无数小时的产物
- 出自行业绝对顶尖之手
- 大师级完成度

### 4. 系统化图案

使用科学式的视觉语言：
- 重复图案
- 完美形状
- 高密度的标记累积
- 分层元素
- 耐心的重复会回报持续的注视

## 设计流派示例

### 具象诗
**哲学：**通过纪念碑式的形式与大胆的几何来传达。

**表达：**
- 巨大的色块
- 雕塑感的字体排印（巨大的词、极小的标签）
- 粗野主义的空间切分
- 波兰海报的劲道遇上勒·柯布西耶
- 用视觉重量与空间张力承载想法
- 文字是稀有而有力的手势

### 色彩语言
**哲学：**色彩作为首要的信息系统。

**表达：**
- 几何精度
- 色彩区域创造含义
- 字体极简：小型无衬线标签
- 约瑟夫·阿尔伯斯的色彩交互遇上数据可视化
- 信息以空间和色彩方式编码
- 文字只为色彩呈现的内容做锚点

### 模拟冥想
**哲学：**借助质感与留白做安静的视觉沉思。

**表达：**
- 纸张纹理、墨水晕染
- 大面积负空间
- 摄影与插画占主导
- 字体排印低声细语（小、克制）
- 日本摄影集美学
- 图像在页面之间呼吸
- 文字出现得很少：只用短句

### 有机系统
**哲学：**自然的聚簇与模块化生长模式。

**表达：**
- 圆润的形式
- 有机的排布
- 色彩取自自然、再经建筑转化
- 信息通过视觉图示承载
- 空间关系与图像符号
- 文字只用于悬浮在空间中的关键标签
- 构图通过空间编排讲故事

### 几何静默
**哲学：**纯粹的秩序与克制。

**表达：**
- 基于网格的精度
- 大胆的摄影或冷峻的图形
- 戏剧化的负空间
- 字体排印精确而极简
- 小而必要的文字，大而安静的区域
- 瑞士形式主义遇上粗野主义的材料诚实
- 传达信息的是结构，不是文字
- 每一处对齐都来自无数次的打磨

## 实施指南

### 低调的引用融入

嵌入概念 DNA，但不声张：
- 小众引用被无形地织入
- 懂的人会直觉地感受到
- 其他人看到的是高超的抽象构图
- 就像爵士乐手引用另一首歌
- 成熟老练，绝不直白
- 引用安静地增加深度

### 色彩取向

**有意为之的配色：**
- 有限的颜色（2-5 种）
- 内聚的系统
- 有目的的关系
- 用 oklch 色彩空间保证精度
- 每个色阶都承载含义

**配色示例：**
```
--color-primary: oklch(0.55 0.22 264)
--color-accent: oklch(0.75 0.18 45)
--color-neutral: oklch(0.90 0.02 264)
--color-dark: oklch(0.25 0.15 264)
```

### 字体排印系统

**偏好细体：**
- 细字重（200-300）
- 干净的无衬线体
- 几何精度
- 标签用小字号
- 冲击时刻用大字号

**字体引入：**
- 在 `./canvas-fonts` 目录中搜索
- 下载所需字体
- 把字体排印带上画布
- 成为艺术的一部分，而不是数字排版产物

### 构图规则

**系统化方法：**
- 重复图案建立节奏
- 完美的几何形状
- 冷静精确的字体排印
- 引用标记暗示出想象中的学科纪律
- 高密度累积构建含义
- 分层图案回报专注

**间距纪律：**
- 没有任何元素掉出页面
- 没有任何元素重叠
- 每个元素都在画布边界之内
- 合理边距不可妥协
- 留出呼吸空间与清晰分隔
- 专业完成度是硬性要求

### Canvas 边界

**技术规格：**
- 默认单页（按需求可多页）
- PDF 或 PNG 输出
- 高分辨率
- 干净的边距
- 收在边界内的构图
- 无瑕疵的版面

## 多页设计系统

创建多页时：

### 方法
- 把第一页当作咖啡桌书里的单页来对待
- 沿同一哲学创建后续页面
- 明显不同却彼此内聚
- 页面有品位地讲故事
- 完全的创作自由

### 一致性要素
- 共享的配色
- 一致的字体排印系统
- 相关联的构图手法
- 视觉语言的连续性
- 贯穿始终的哲学线索

### 变化策略
- 每页有独特的转折
- 不同的焦点
- 多样的空间排布
- 互补的图案
- 渐进推进的视觉叙事

## 执行清单

定稿之前：

- [ ] 哲学指导每一个决策
- [ ] 90% 视觉，文字至多 10%
- [ ] 文字极简且已融入
- [ ] 没有重叠，没有元素掉出页面
- [ ] 边距与间距完美无瑕
- [ ] 构图与艺术内聚统一
- [ ] 看起来经过精心打磨
- [ ] 大师级完成度清晰可见
- [ ] 成熟老练，绝无业余感
- [ ] 可以陈列在博物馆里
- [ ] 证明无可争议的专业能力
- [ ] 版面无瑕疵
- [ ] 每个细节都完美

## 质量标准

### 要避免
- 卡通化审美
- 业余完成度
- 文字过重的构图
- 随意摆放
- 元素重叠
- 间距不一致
- 一眼可见的 AI 生成感
- 缺乏打磨

### 要达到
- 博物馆级质量
- 杂志级水准
- 艺术品级别的地位
- 无数小时打磨出来的外观
- 行业顶尖的工艺
- 哲学上的连贯
- 视觉上的成熟
- 系统化的精确

## 打磨流程

### 第一遍
依据哲学与原则进行创作。

### 第二遍（关键）
- 不要再加图形
- 打磨已有的东西
- 做到极度清晰锐利
- 尊重极简主义哲学
- 增强与艺术的内聚
- 让已有元素更有艺术感
- 打磨，而不是扩张

### 最终校验
用户已经说过："还不够完美。必须完美无瑕，是工艺上的杰作，就像马上要陈列进博物馆一样。"

交付之前，按这个标准执行。

## 输出格式

**必需文件：**
1. 设计哲学（.md 文件）
2. 视觉表达（.pdf 或 .png）

**哲学文件包含：**
- 流派名称
- 4-6 段的哲学阐述
- 视觉原则
- 执行指引

**Canvas 文件包含：**
- 视觉诠释
- 极少文字
- 系统化构图
- 专家级完成度

## 适用场景

Canvas 设计适用于：
- 品牌识别系统
- 海报设计
- 视觉宣言
- 设计系统文档
- 艺术作品与构图
- 概念性视觉框架
- 编辑设计
- 展览物料
- 咖啡桌书
- 设计哲学演示
