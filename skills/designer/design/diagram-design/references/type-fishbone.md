# 鱼骨图 / 石川图（根因分析）

**适用场景：** 结构化根因分析。一个观察到的效应，原因按类别分组，子因挂在各类别之下。事故复盘的标准产物：当读者需要看到*调查过什么*而不只是结论时使用。

## 布局约定

- **主骨（Spine）。** 一条水平线（`ink`，1.2px）在纵向中心 `CY` 上自左向右延伸，末端带箭头扎进右侧头部的**效应框**：SKILL.md §6 的节点盒模式（[primitives-core.md](primitives-core.md#node-box--full-pattern)），框内写观察到的效应陈述。
- **大骨（Bones）。** 类别线是与主骨成固定 **60°** 角的直斜线，在主骨上下交替，沿主骨等距分布。每根大骨的外端带一个小的标签样式盒（`rx=4`，不是胶囊），写类别名：`node-name` 角色，12px，字重 600。
- **子因。** 短横刻线（32px，`soft`）从每根大骨沿其长度的固定点分支出来，每条刻线配一个 `sublabel` 角色 9px 的子因标签，坐在刻线开口端之外。
- **斜线豁免。** SKILL.md §6 规则 1（强制的直角圆角拐弯）不适用于 60° 大骨：它们是这个类型的定义性语法。豁免**只覆盖大骨与子因刻线**；鱼骨图里任何其他连接线（如气泡引线、交叉引用箭头）仍用直角圆角拐弯。
- **焦点规则。** 恰好一根大骨是被确认的根因：它的线用 `accent`，类别标签用 `accent-tint` 填充 + `accent` 描边。效应框样式与之相同（`accent-tint` 填充、`accent` 描边），因为它是整张图的标题。这一对（根因大骨 + 效应框）就是全部 2 个 accent 预算；其他每根大骨、标签和刻线保持 `ink` / `muted` / `soft`。
- **绘制顺序：** 背景 → 主骨 → 大骨 → 子因刻线 → 类别标签盒 → 效应框 → 图例。先线后盒，盒的填充才能干净地盖住线的末端。

## 数学

主骨在 `y = CY`，效应框左缘在 `x = HEAD`，第 `k` 根大骨（1 起始，k = 1..6）的附着点为：

```
attach_x(k) = HEAD - 160 - k * 160
```

大骨在主骨上下交替（`k` 奇数在上，`k` 偶数在下）。大骨远端（类别标签所在处）是从附着点按 60° 偏移取整得到：

```
dx = -96
dy = ∓168        (minus = above, plus = below)
far_x(k) = attach_x(k) + dx
far_y(k) = CY ∓ 168
```

### 预计算参考（5 骨布局，HEAD=1200，CY=320）

| 骨 `k` | 类别槽位 | 侧 | `attach_x` | `far_x, far_y` |
|---|---|---|---|---|
| 1 | 第一 | 上 | 880 | 784, 152 |
| 2 | 第二 | 下 | 720 | 624, 488 |
| 3 | 第三 | 上 | 560 | 464, 152 |
| 4 | 第四 | 下 | 400 | 304, 488 |
| 5 | 第五 | 上 | 240 | 144, 152 |

第 6 根骨（下侧）会附着在 `x=80`，远端 `(-16, 488)`，类别标签会从 `x=-76` 延伸到 `x=44`，而 viewBox 从 `x=-40` 起。会被裁掉。**在 `HEAD=1200` 下 5 根是上限**：要画第 6 根，就把 `HEAD` 与 viewBox 宽度各加宽至少 160，viewBox 原点保持在 `-40`。两者必须一起动：只加宽 `HEAD` 会把 200px 的效应框推到 `1360..1560`，越过 `1440` 右缘，等于用右边裁掉的效应换左边裁掉的标签。或者砍掉一个类别。

**子因刻线**位于大骨的 `m/6` 分数处（两条刻线取 `m = 2, 4`；一条取 `m = 3`），坐标因此落在 4px 网格上：

```
tick_x(k, m) = attach_x(k) - 16 * m
tick_y(k, m) = CY ∓ 28 * m
```

刻线本身是从 `(tick_x, tick_y)` 到 `(tick_x - 32, tick_y)` 的 32px 水平线；标签坐在开口端之外，`text-anchor="end"`，位于 `x = tick_x - 36`，`y = tick_y - 4`（上侧骨）或 `tick_y + 12`（下侧骨）。

## 复杂度预算

| 限额 | 规则 |
|---|---|
| 最大类别（大骨）数 | `HEAD=1200` 下 5 根。第 6 根需要加宽画布，见几何一节 |
| 每根大骨最大子因数 | 3 |
| 子因总数上限 | 18 |
| accent 元素上限 | 2（根因大骨+标签，效应框） |

## 反模式

- **默认画布上超过 5 根骨。** 第 6 根标签会裁出 viewBox。要么有意地同时加宽 `HEAD` 与 viewBox 宽度，要么按子系统拆成两张鱼骨图。
- **子因复述类别。** "Deploy" 大骨下挂一个叫 "deployment issue" 的子因，只加了一个节点，没加任何信息。
- **没有子因的大骨。** 空类别是占位符，不是发现：删掉它，或等下面有东西再画。
- **根因强调超过一个。** 两个类别都被确认，那就是两张图（或合并成因），不是两根 accent 骨。2 个 accent 的预算支撑着"这就是答案"的信号。
- **用鱼骨图表达一连串失败。** 按时间顺序发生的事情链是时间线或时序图：鱼骨图表达的是*一个*效应的原因，不是编年史。
- **照搬经典 6M 模板（Man/Machine/Material/Method/Measurement/Environment）却留空类别。** 类别从实际调查中来，不是一个等着回头填的通用清单。
- **效应框写成解决方案。** "加一个 p99 告警"是修复措施，不是观察到的效应。框里陈述的是看到了什么：一个症状、一个测量、一起事故，绝不是补救办法。
