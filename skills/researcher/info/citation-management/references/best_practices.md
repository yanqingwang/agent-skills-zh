# 最佳实践

检索策略、元数据提取、BibTeX 质量与校验实践。

## 最佳实践

### 检索策略

1. **先宽后窄**：
   - 从通用术语入手，了解该领域
   - 用具体关键词与过滤器收窄
   - 使用同义词与相关词

2. **利用多个来源**：
   - Google Scholar 用于全面覆盖
   - PubMed 用于生物医学方向
   - arXiv 用于预印本
   - 合并结果以保证完整性

3. **利用引文网络**：
   - 对奠基性论文查看 "Cited by"
   - 回顾关键论文的参考文献
   - 用引文网络发现相关工作

4. **记录你的检索过程**：
   - 保存检索式与日期
   - 记录结果数量
   - 注明施加过的任何过滤器或限制

### 元数据提取

1. **只要有 DOI 就用 DOI**：
   - 最可靠的标识符
   - 指向出版物的永久链接
   - 通过 CrossRef 获取最佳元数据来源

2. **验证提取到的元数据**：
   - 检查作者姓名是否正确
   - 核实期刊/会议名称
   - 确认出版年份
   - 校验页码与卷号

3. **处理边界情况**：
   - 预印本：包含仓储与 ID
   - 预印本后来正式发表：使用正式发表版本
   - 会议论文：包含会议名称与地点
   - 书籍章节：包含书名与编者

4. **保持一致性**：
   - 使用一致的作者姓名格式
   - 统一期刊缩写
   - 在 BibTeX 的 `doi` 字段中只放裸标识符；在正文中使用解析器 URL

### BibTeX 质量

1. **遵循惯例**：
   - 使用有意义的引文键（FirstAuthor2024keyword）
   - 用 {} 保护标题中的大小写
   - 页码范围用 --（不用单连字符）
   - 已分配 DOI 时包含 DOI 字段

2. **保持整洁**：
   - 移除不必要的字段
   - 不保留冗余信息
   - 格式一致
   - 定期校验语法

3. **系统化组织**：
   - 按年份或主题排序
   - 把相关论文归到一起
   - 不同项目使用不同的文件
   - 合并时小心，避免重复

### 校验

1. **尽早且频繁地校验**：
   - 添加引文时就检查
   - 提交前校验完整的参考文献
   - 任何人工编辑之后重新校验

2. **及时修复问题**：
   - DOI 失效：找到正确标识符
   - 字段缺失：从原始来源提取
   - 重复项：挑选最佳版本，删除其余
   - 格式错误：安全时使用自动修复

3. **关键引文做人工复核**：
   - 核实关键论文被正确引用
   - 检查作者姓名与出版物一致
   - 确认页码与卷号
   - 确保 URL 仍然有效
