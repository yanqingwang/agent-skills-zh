# 名人人设分析器

## 任务

利用研究产出，提取一位公众人物持久稳定的认知架构。

不要为角色扮演或舞台化模仿做优化。
优化的目标是一个可用的思维框架：捕捉他们"怎么想"，而不是他们"说了什么"。

产出要有足够的辨识度：去掉名字之后，熟悉此人的读者仍能认出这是谁的思维方式。

---

## 提取目标

### 1. 表达 DNA

提取语言指纹：让此人的表达可以被认出来的那些模式。

- **语气**：正式/随意，热络/疏离，挑衅/克制
- **节奏**：句子韵律，短促有力的碎片句 vs. 长段流畅的解释
- **比喻清单**：他们的类比取自哪些领域？（战争、体育、烹饪、物理等）
- **压缩程度**：他们把事情解释完整，还是默认听众跟得上？
- **强调手法**：他们怎么把一个观点讲透？（重复、对比、层层加码、轻描淡写）
- **确定性标记**：他们如何表达"确定"与"不确定"？
- **幽默风格**：自嘲、荒诞、冷面、好斗，或没有幽默
- **标志性短语**：反复出现的框架、口头习惯、有辨识度的用词

校验标准：去掉名字后，仅凭一段 100 词的样本，别人能否认出这是此人？

### 2. 心智模型

提取他们反复用来理解世界的概念框架。

对每个模型：
- **名称**：简短的标签
- **一句话定义**：它捕捉了什么
- **最先看到什么**：这个透镜最先注意到什么
- **过滤掉什么**：这个透镜系统性地忽略什么
- **如何重构问题**：套用这个模型会如何改变你对一个处境的思考方式
- **证据锚点**：至少 2 个在不同情境下应用此模型的实例
- **失效模式**：这个模型什么时候会把他们带偏？

质量门：每个候选心智模型必须在以下 3 项中至少通过 2 项：
1. **跨情境复现**：出现在至少 2 个不同领域/情境中
2. **生成力**：能帮助预测他们对陌生、未研究过问题的立场
3. **独占性**：有实质辨识度，不是任何聪明人都会讲的通用道理

通过全部 3 项 → 保留为心智模型。
通过 1–2 项 → 降级为决策启发式。
通过 0 项 → 丢弃。

### 3. 决策启发式

提取他们的快速判断规则："如果 X，那么 Y"式的模式。

- 大多数决策中他们在优化什么
- 他们愿意牺牲什么
- 什么时候快速行动（低权衡）
- 什么时候等待（高权衡）
- 什么样的证据会让他们改变想法
- 什么会触发彻底反转，什么他们会固执坚持

### 4. 反模式与边界

提取他们拒绝什么，以及在哪里划界。

- 他们反复警告别人不要做什么
- 他们认为幼稚、偷懒或软弱的想法
- 他们拒绝参与的模式
- 他们对自身局限坦白的地方
- 明说过的盲点与承认过的弱点

### 5. 张力与矛盾

提取定义此人复杂性的内在张力。

给矛盾分类：
- **时间性**：随时间演变的观点（记录轨迹）
- **情境性**：不同领域适用不同原则（记录领域边界）
- **固有性**：始终未解决的核心价值张力（作为深度来源记录，而不是当成 bug）

不要消解矛盾。保留它们。

### 6. 思想谱系

提取影响网络。

- **受影响于**：谁的思想塑造了他们？（具体思想家、学派、传统）
- **分道于**：他们在哪些地方明确不同意自己的思想来源？
- **影响谁**：谁引用他们、跟随他们的路径，或在他们的工作之上构建？
- **思想传统**：他们属于（或拒绝）哪个更大的学派或运动？

### 7. Agentic Protocol 推导

从心智模型出发，推导此人回答一个陌生问题之前会研究什么。

- 基于其心智模型，他们会调查哪些维度？
- 形成观点之前他们会问什么问题？
- 他们会信任哪些来源，不信任哪些？
- 他们最想先知道什么？

这些内容将用于在人设构建器中生成 Agentic Protocol。

## 输出格式

```text
Expression DNA:
  Tone: ...
  Cadence: ...
  Metaphors: ...
  Compression: ...
  Signature moves: ...
  Humor: ...
  Blind test confidence: [high/medium/low]

Mental Models: [3-7]
  - {model name}: {definition}
    Evidence: ...
    Sees first: ...
    Filters out: ...
    Failure mode: ...
    Gates passed: [cross-context, generative, exclusive]

Decision Heuristics: [5-10]
  - {rule}: {when/how applied}

Anti-patterns: [...]
Honest Boundaries: [...]

Contradictions: [2+ tensions]
  - Type: [temporal/contextual/inherent]
  - Description: ...

Intellectual Genealogy:
  Influenced by: ...
  Diverged from: ...
  Influenced: ...

Agentic Protocol Seeds:
  When facing a new problem, this person would first: ...
  They would research: ...
  They would distrust: ...
```

## 规则

- 用用户的语言书写
- 区分证据与推断：始终标明哪边是哪边
- 只在有助于表达 DNA 时引用很短的关键短语
- 让此人在思想上可被认出，而不是在舞台上被模仿
- 不要把素材笔记拼缝成引语集
- 保留矛盾：它们是特性，不是缺陷
- 某个维度证据单薄时，明确说出来，不要编造深度
