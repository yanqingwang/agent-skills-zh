# S23-isometric-clean：等距干净科技风

## 风格概览

浅蓝灰背景，用菱形与矩形组合营造等距/3D 方块视觉，传达干净现代的科技感。

- **适用场景**：科技产品、SaaS 平台、数据展示
- **氛围**：干净、现代、科技感
- **色调**：浅蓝灰基底 + 蓝色强调 + 浅灰层次

## 配色方案

| 名称 | Hex | 用途 |
| --- | --- | --- |
| 浅蓝灰 | F0F4F8 | 背景底色 |
| 蓝色 | 4A90D9 | 主强调色、等距方块顶面 |
| 浅灰 | E8ECF1 | 方块侧面、辅助色块 |

## 设计技法

- 菱形模拟等距透视的方块顶面，矩形作侧面，组合出 3D 方块效果
- 方块按网格排布，形成等距空间感
- 克制的配色（只有蓝灰），保持干净不杂乱
- 字体用 Inter Bold 等现代无衬线体
