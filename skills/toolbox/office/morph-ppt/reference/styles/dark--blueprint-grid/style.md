# S15-blueprint-grid：工程蓝图网格

## 风格概览

深蓝背景、白色网格线与金色标记，营造精确的工程制图美感。

- **适用场景**：技术规划、工程蓝图、系统架构
- **氛围**：精确、专业、工程感
- **色调**：深蓝 + 白色网格 + 金色点缀

## 配色方案

| 名称 | Hex | 用途 |
| --- | --- | --- |
| 深蓝 | 1B3A5C | 背景 |
| 亮蓝 | 4A90D9 | 高亮色、标题 |
| 白色 | FFFFFF | 网格线、正文文字 |
| 金色警示 | E8C547 | 警示标记、CTA 按钮 |

## 设计技法

- 用 rect 绘制等距横/竖网格线（opacity 0.25），模拟蓝图方格纸
- 用 ellipse 作定位标记点，暗示坐标系中的关键节点
- 所有形状以低透明度叠加，保持蓝图层级
- 字体用等宽或加粗无衬线体，强化工程制图美感
