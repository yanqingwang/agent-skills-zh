# Brand Refresh：品牌焕新

## 风格概览

暖奶油色背景上的多彩色块拼贴，营造活泼时尚的品牌视觉。

- **适用场景**：品牌发布、企业形象焕新、创意提案
- **氛围**：温暖、时尚、多彩、现代
- **色调**：暖色基底，多彩色块

## 配色方案

| 名称 | Hex | 用途 |
| --- | --- | --- |
| 暖奶油色 | F5F0E8 | 背景（羊皮纸纹理） |
| 深海军蓝 | 162040 | 标题文字 |
| 蓝色 | 1A6BFF | 主色块色 |
| 橙色 | F4713A | 色块强调 |
| 青色 | 00C9D4 | 色块次色 |
| 薄荷绿 | 7EC8A0 | 色块次色 |
| 粉色 | E8749A | 色块高亮 |
| 弱化文字 | 9A9080 | 弱化的文字 |
| 正文字色 | 6B6355 | 正文文字 |

## 字体排印

- 标题：Arial 52pt Bold
- 正文：Arial 15pt
- 标签：Arial 11pt

## 场景元素

- 6 个矩形色块（blk-a 至 blk-f），在右侧组成马赛克网格
- 色块在每页之间重排、缩放与位移
- 使用图片素材（portrait1.jpg、portrait2.jpg、abstract1.jpg、team1.jpg）；仅作风格参考时可忽略图片部分

## 设计技法

- 色块马赛克版式：色块在每页构成不同的网格图案
- 照片嵌入色块网格之中
- 经典分栏版式：左侧文字 + 右侧多彩色块
- Morph 转场让色块平滑滑动与缩放
- 6 页幻灯片
