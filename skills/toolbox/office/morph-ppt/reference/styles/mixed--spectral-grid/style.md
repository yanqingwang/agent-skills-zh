# Spectral Grid：活力融合

## 风格概览

融合包豪斯色块 + 渐变射线扇 + 马赛克瓷砖。深靛蓝基底，琥珀色、青柠色与珊瑚色点缀。

- **适用场景**：创意科技、创新展示、设计大会
- **氛围**：鲜活、有能量、创新、实验感
- **色调**：深靛蓝，配多彩点缀

## 设计技法

- !!prism Actor（对角渐变面板）在每页旋转 + 变形
- 渐变射线扇
- 马赛克瓷砖图案
- 靶心圆环元素
