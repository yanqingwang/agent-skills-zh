# Glassmorphism VC：投资基金

## 风格概览

天蓝背景，3D 渐变球体与磨砂玻璃 roundRect 卡片。现代玻璃拟态美感。

- **适用场景**：VC 基金、投资路演、金融科技、初创推介
- **氛围**：现代、高端、精致、可信
- **色调**：浅蓝，配渐变球体

## 设计技法

- 玻璃拟态卡片（半透明 roundRect）
- 3D 渐变球体
- 堆叠球体组合
- 渐变条形柱状图
- 磨砂玻璃效果
