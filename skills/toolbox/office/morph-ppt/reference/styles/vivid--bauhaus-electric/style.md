# Bauhaus Electric：创意机构

## 风格概览

电光蓝 + 酸性青柠的大胆几何矩形，包豪斯美感。特色是双形状 Morph 旅程与平行四边形几何。

- **适用场景**：创意机构、设计工作室、大胆品牌形象
- **氛围**：大胆、有能量、几何感、电光感
- **色调**：电光蓝 + 酸性青柠

## 设计技法

- !!blockA（蓝）+ !!blockB（青柠）双形状 Morph
- 平行四边形几何
- 八角星号点缀
- 原生几何形态
