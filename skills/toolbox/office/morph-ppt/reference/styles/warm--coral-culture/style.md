# Coral Culture：企业文化演示

## 风格概览

水平蓝到珊瑚色渐变背景，配竖向装饰条簇。极端的字体排印对比，浅/深幻灯片交替。

- **适用场景**：企业文化演示、HR 演示、团队展示
- **氛围**：温暖、文化感、以人为本、动感
- **色调**：蓝到珊瑚色渐变

## 设计技法

- 水平渐变背景（蓝 → 珊瑚色）
- 竖条簇（抽象天际线）
- 圆环元素
- 相邻幻灯片之间的硬对比
