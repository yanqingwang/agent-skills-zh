# S16-watercolor-wash：水彩晕染

## 风格概览

暖白底色，用极低透明度的彩色椭圆模拟水彩晕染效果，营造柔和诗意的氛围。

- **适用场景**：艺术、文创、茶道、婚礼
- **氛围**：柔和、诗意、艺术感
- **色调**：暖白底 + 天蓝/蜜桃/鼠尾草绿/薰衣草紫多色晕染

## 配色方案

| 名称 | Hex | 用途 |
| --- | --- | --- |
| 暖白 | FFFDF7 | 背景底色 |
| 天蓝 | 7AADCF | 水彩晕染色块 |
| 蜜桃色 | E8A87C | 水彩晕染色块 |
| 鼠尾草绿 | B5C99A | 水彩晕染色块 |
| 薰衣草紫 | D4A5C9 | 水彩晕染色块 |

## 设计技法

- 所有装饰形状均为椭圆，不用矩形，保持圆润柔和
- 所有色块透明度极低（0.06-0.12），模拟水彩颜料渗入纸面的效果
- 多个椭圆叠压产生自然的混色与边缘渐变
- 字体用细体/衬线体，呼应水彩质感
