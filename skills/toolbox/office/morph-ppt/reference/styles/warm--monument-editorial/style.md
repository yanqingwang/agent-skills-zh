# Monument Editorial：纯字体排印

## 风格概览

暖纸色背景，陶土墨色与单一赤陶色点缀。零渐变，纯字体排印取向。

- **适用场景**：建筑、奢侈品牌、编辑类杂志、工作室品牌
- **氛围**：纪念碑感、编辑感、考究、字体排印导向
- **色调**：暖纸色，配赤陶色

## 设计技法

- !!block（赤陶色 rect）形态变换：细条 → 横带 → 半面板 → 底部条 → 中央方块 → 全页
- 纯字体排印，零渐变
- 纪念碑式超大文字
- 极简配色
