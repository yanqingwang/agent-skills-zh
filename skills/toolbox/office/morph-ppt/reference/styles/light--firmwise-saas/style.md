# Firmwise SaaS：干净高效

## 风格概览

干净极简的 SaaS 设计：浅蓝灰背景配电光紫点缀。特色是切角卡片（右上角切角）与三列数据版式。

- **适用场景**：SaaS 平台、效率工具、B2B 软件、效率仪表盘
- **氛围**：干净、高效、现代、可信
- **色调**：浅蓝灰，配电光紫点缀

## 配色方案

| 名称 | Hex | 用途 |
| --- | --- | --- |
| 背景 | #EFF2F7 | 浅蓝灰 |
| 主色 | #7B3FF2 | 电光紫 |
| 白色 | #FFFFFF | 卡片、文字 |
| 深色 | #2C3E50 | 主文字 |
| 暗文字 | #8B9AA8 | 辅助文字 |

## 设计技法

- 切角卡片（右上角切角）
- 三列数据版式
- 干净极简的留白
- 电光紫作强调色
