# 页面 CRO 实验点子

## 首页实验

### 首屏区（Hero Section）

| 测试 | 假设 |
|------|------------|
| 主标题变体 | 具体信息 vs. 抽象信息 |
| 副标题清晰度 | 增加/打磨副标题以支撑主标题 |
| 首屏以上放 CTA | 是否放显眼的 CTA |
| 首屏视觉形式 | 截图 vs. GIF vs. 插画 vs. 视频 |
| CTA 按钮颜色 | 测试对比度与可见性 |
| CTA 按钮文案 | "开始免费试用" vs. "立即开始" vs. "观看演示" |
| 交互式演示 | 让访客立刻与产品互动 |

### 信任与社会证明

| 测试 | 假设 |
|------|------------|
| 客户 Logo 位置 | 首屏区 vs. 首屏以下 |
| 首屏放案例研究 | 立刻展示成果 |
| 信任徽章 | 增加安全、合规、奖项标识 |
| 主标题里的社会证明 | "已有 10,000+ 团队加入"类文案 |
| 用户评价位置 | 首屏以上 vs. 独立专区 |
| 视频用户评价 | 比文字引用更有吸引力 |

### 功能与内容

| 测试 | 假设 |
|------|------------|
| 功能呈现方式 | 图标+简述 vs. 详细分节 |
| 板块顺序 | 把高价值功能往前放 |
| 次级 CTA | 全页增/删次级 CTA |
| 卖收益 vs. 卖功能 | 以结果开篇 |
| 对比板块 | 与竞品或现状对比 |

### 导航与 UX

| 测试 | 假设 |
|------|------------|
| 吸顶导航 | 常驻导航栏带 CTA |
| 导航菜单顺序 | 高优先级项放边缘位置 |
| 导航栏 CTA 按钮 | 在导航栏加显眼按钮 |
| 支持组件 | 人工在线客服 vs. AI 聊天机器人 |
| 页脚优化 | 更清晰的次级转化 |
| 离站意图弹窗 | 挽留即将离开的访客 |

## 定价页实验

### 价格呈现

| 测试 | 假设 |
|------|------------|
| 按年 vs. 按月展示 | 突出优惠力度或做简化 |
| 价格点位 | $99 vs. $100 vs. $97 的定价心理学 |
| "最受欢迎"徽章 | 突出目标套餐 |
| 档位数量 | 3 个 vs. 4 个 vs. 2 个可见选项 |
| 价格锚定 | 调整套餐顺序来锚定预期 |
| 定制企业档 | 直接展示 vs. "联系销售" |

### 定价 UX

| 测试 | 假设 |
|------|------------|
| 定价计算器 | 让按量计费更清晰 |
| 引导式定价流程 | 多步向导 vs. 对比表格 |
| 功能对比形式 | 表格 vs. 可展开分节 |
| 月付/年付切换 | 突出年付优惠 |
| 套餐推荐问答 | 帮访客做选择 |
| 结账流程长度 | 选定套餐后还需要几步 |

### 异议处理

| 测试 | 假设 |
|------|------------|
| FAQ 板块 | 回应价格异议 |
| ROI 计算器 | 展示价值相对成本 |
| 退款保证 | 放在显眼位置 |
| 按人拆分价格 | 让团队套餐更透明 |
| 功能包含说明 | 讲清每个档位有什么 |
| 竞品对比 | 并排对比价值 |

### 信任信号

| 测试 | 假设 |
|------|------------|
| 价值向用户评价 | 专讲 ROI 的引用语 |
| 客户 Logo | 放在定价区附近 |
| 平台评分 | G2/Capterra 评分 |
| 案例研究摘要 | 具体的价格/价值成果 |

## 演示申请页实验

### 表单优化

| 测试 | 假设 |
|------|------------|
| 字段数量 | 字段越少，完成率越高 |
| 多步 vs. 单步 | 用进度条给用户打气 |
| 表单位置 | 首屏以上 vs. 内容之后 |
| 电话字段 | 收 vs. 不收 |
| 字段富化 | 能自动填充的字段就藏起来 |
| 表单标签 | 放字段内 vs. 放字段上方 |

### 页面内容

| 测试 | 假设 |
|------|------------|
| 表单上方先讲收益 | 提出要求前先强化价值 |
| 演示预览 | 用视频/GIF 展示演示体验 |
| "你将学到什么" | 清晰设定预期 |
| 表单附近放用户评价 | 降低决策点的摩擦 |
| 表单下方放 FAQ | 回应常见异议 |
| 视频 vs. 文字 | 解释价值的形式选择 |

### CTA 与分流

| 测试 | 假设 |
|------|------------|
| CTA 文案 | "预约演示" vs. "安排 15 分钟通话" |
| 即时演示选项 | 在真人演示之外提供即时演示 |
| 个性化文案 | 基于访客数据/来源 |
| 移除导航 | 减少页面干扰 |
| 日历集成 | 页内预约 vs. 外部链接 |
| 资质分流 | 一部分自助，一部分转销售 |

## 落地页实验

### 信息匹配

| 测试 | 假设 |
|------|------------|
| 主标题匹配 | 与广告文案完全一致 |
| 视觉匹配 | 与广告素材一致 |
| 优惠一致 | 与广告承诺的优惠一致 |
| 分受众页面 | 每个细分人群不同页面 |

### 转化聚焦

| 测试 | 假设 |
|------|------------|
| 移除导航 | 单一焦点页面 |
| CTA 重复出现 | 全页多个 CTA |
| 表单 vs. 按钮 | 直接留资 vs. 点击跳转 |
| 紧迫感/稀缺感 | 若真实存在，测试相应文案 |
| 社会证明密度 | 数量与位置 |
| 加入视频 | 用视频讲清优惠 |

### 页面长度

| 测试 | 假设 |
|------|------------|
| 短页 vs. 长页 | 快速转化 vs. 完整论证 |
| 仅首屏内容 | 几乎无需滚动 |
| 板块顺序 | 最重要的内容放最前 |
| 移除页脚 | 消除导航出口 |
