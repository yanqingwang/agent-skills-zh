# 投资人材料（Investor Materials）

构建一致、可信、经得起质询的面向投资人的材料。

## 何时启用

- 创建或修订 pitch deck
- 撰写投资人 memo 或 one-pager
- 搭建财务模型、里程碑计划或资金用途表
- 回答加速器或孵化器的申请问题
- 让多份融资文档围绕同一个唯一事实来源对齐

## 黄金法则

所有投资人材料之间必须彼此一致。

在动笔之前，先创建或确认一个唯一事实来源（source of truth）：
- traction（业务增长）数据指标
- 定价与收入假设
- 融资规模与融资工具（raise size and instrument）
- 资金用途
- 团队成员简介与头衔
- 里程碑与时间线

一旦出现相互矛盾的数字，先停下来解决，再开始起草。

## 核心工作流

1. 盘点所有权威事实
2. 找出缺失的假设
3. 选择材料类型
4. 以明确的逻辑起草材料
5. 将每一个数字与事实来源交叉核对

## 各类材料的撰写要点

### Pitch Deck（融资路演稿）
推荐结构：
1. 公司 + wedge（切入点）
2. 问题
3. 解决方案
4. 产品 / 演示
5. 市场
6. 商业模式
7. traction（业务增长数据）
8. 团队
9. 竞争 / 差异化
10. 融资请求（ask）
11. 资金用途 / 里程碑
12. 附录

如果用户需要网页原生形式的 deck，请将本 Skill 与 `frontend-slides` 搭配使用。

### One-Pager / Memo
- 用一句干净利落的话说明公司是做什么的
- 展示"为什么是现在"（why now）
- 尽早呈现 traction 和佐证材料
- 让融资请求（ask）精确明确
- 保持所有论断易于核实

### 财务模型
包含：
- 明确写出的假设
- 需要时给出悲观 / 基准 / 乐观（bear / base / bull）三种情景
- 清晰的逐层收入逻辑
- 与里程碑挂钩的支出
- 在决策取决于假设的关键处做敏感性分析

### 加速器申请
- 严格回答所问的问题
- 优先呈现 traction、洞察和团队优势
- 避免浮夸之词
- 保持内部指标与 deck 和财务模型一致

## 应避免的危险信号

- 无法核实的论断
- 没有假设支撑的模糊市场规模测算
- 团队角色或头衔前后不一
- 收入计算加总不齐
- 在假设本身脆弱的地方表现出过度的确定性

## 质量关卡

交付之前检查：
- 每个数字都与当前事实来源一致
- 资金用途与收入分层加总正确
- 假设清晰可见，而非被埋没
- 故事清晰，不含夸张营销话术
- 最终材料在合伙人会议（partner meeting）上经得起质询
