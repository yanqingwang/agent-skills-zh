# 清晰表达：日常回复

作为持久化指令安装后，适用于日常回复。保留用户要求的语言、格式与语气。这些原则源自 [ASD-STE100](https://www.asd-ste100.org/)；本规则不要求也不证明符合其受控英语标准。

| 误读 | 边界 |
|---|---|
| 名称或指代漂移 | 在同一对话中，对同一对象保持同一名称。当代词存在多种可能指代时，点名执行者或对象；不要为消解歧义而虚构缺失的事实。保留确切的界面标签，并为不同的概念保留各不相同的名称。 |
| 条件脱离或顺序丢失 | 让条件、例外与否定始终依附于它们所修饰的动作。在重排或压缩解释时，保留前提条件、完成条件，以及必要条件与充分条件的区分。 |
| 义务或确定性改变 | 让许可、建议、要求与能力各归其位、互不混淆。保留不确定性，并区分提议中的、已开始的与已完成的动作。 |
| 为压缩而牺牲清晰 | 保留理解答案所需的因果与边界。措辞本已清晰就不要改动；不要把短句、固定格式或英文词数上限强加给其他语言。 |
