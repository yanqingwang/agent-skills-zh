## Frontend Slides 固定舞台策略

当本设计系统被 `frontend-slides` Skill 使用时，请把最终演示文稿生成为**固定 1920×1080 舞台**，整体等比缩放以适配浏览器视口。演示文稿在所有屏幕（含手机）上都应保持 16:9 幻灯片画布；可以留黑边（letterbox）或留白边（pillarbox），但不应为移动端重排幻灯片内容。

本策略的优先级高于本文件后面描述的任何源模板响应式行为。如果后文说原模板是视口流式（viewport-fluid），那只当作源历史，不视为 `frontend-slides` 的目标生成模型。

即使源模板最初用 `100vw`、`100vh`、`vw`、`vh` 或 `clamp()` 这类视口流式 CSS 实现，本策略同样适用。把这些数值当作要换算进 1920×1080 舞台坐标的设计比例，而不是生成文稿里实际生效的响应式规则。

最终输出请使用 `deck-stage.js` 或等效的内联舞台缩放器：每页按 1920×1080 渲染，用一次 transform 缩放整个舞台，并核对渲染截图，检查文字溢出与面板重叠。


## 概述

Stencil & Tablet 是一套**海报般响亮、文字主导**的演示系统。前提是单一展示字面 Stardos Stencil 包办每个标题、每个数字、每个精选瞬间，其标志性的镂版断墨让每个字形带一点做旧的工业语域。配角是 Barlow Condensed（超重 600–900、全大写、宽裕字距）跑全部元数据、外壳、胶囊、图例，Inter 则处理那少量正文段，它们多半只是给上方响亮文字作图注。

视觉逻辑是**色块即布局**。骨奶油场地（`{colors.bone}` — #E2DCC9）是默认页面，其上坐着饱和复古印刷色的圆角"石板"卡片，赭棕、洋红粉、橙、青、深蓝、芥末黄、橄榄绿。这些强调不是柔和色，它们读作印刷墨，略压暗却分明饱和。卡片承担划分画布的工作，隔着半个房间也能认出一页的结构，因为色块是几何铺贴的。一个深骨色变体（`{colors.black}` 场地配骨色文字）出现在议程式与粗体陈述页上。

排印语域是**巨大且全大写**。封面标题 220px。石板卡里的数字 220–240px。分节断口 540px（没错，单字高度超过画布一半）。陈述标题 120px。连统计数字都从 160px 起步。系统的身份依赖把文字跑到多数文稿不可能的尺寸，Stencil & Tablet 把尺度当主要表现工具、颜色当次要工具，正文只作配角。

纵深是**扁平加圆角外壳**。没有投影，没有渐变。卡片带宽裕 border-radius（22–26px）与饱和填充，这就是整套纵深系统。卡内分隔是 1.5–2px 实线暖墨细线，比 Soft Editorial 耳语般的虚线更重，因为系统整体视觉分量更大。

**密度取向：高且笃定。** Stencil & Tablet 本就该显得填满。典型一页大部分画布被色块覆盖，石板卡铺贴、动作条横贯、分节数字占半页。骨色场地主要作为卡片间的间隙（22–28px）与 64px 页面外内边距露出来。在这套系统里读着别扭的页，是大半空着骨色的页，设计需要色块撑住身份。例外是分节断口页，深色场地上一枚 540px 数字*就是*设计，空白是刻意的。

**关键特征：**
- 多数页骨色（`{colors.bone}`）场地，议程式与粗体断口页用黑场地配骨色文字。
- Stardos Stencil 用于每个标题、每个数字、每个精选镂版瞬间，带断墨的镂版字形是系统身份。
- Barlow Condensed 超重全大写用于全部外壳、元数据、胶囊、图例、标签，字距宽裕（0.06–0.14em）。
- Inter 作正文，角色小，支撑上方响亮文字。
- 七色强调调色板（`{colors.sienna}`、`{colors.magenta}`、`{colors.orange}`、`{colors.teal}`、`{colors.blue}`、`{colors.mustard}`、`{colors.olive}`）加纸色（`{colors.paper}`），作整卡填充。
- 22–26px border-radius 的石板卡，装一个巨型镂版数字，下压镂版标题，再压 Inter 正文。数字通常填满卡片高度一半以上。
- 数字跑得极大，分节断口 540px、石板卡 220–240px、统计 160px。
- 所有标题全大写，所有元数据全大写。句式只出现在 Inter 正文里。
- 无投影、无渐变，扁平色块配圆角。

## 颜色

### 调色板

- **骨色**（`{colors.bone}` — #E2DCC9）：默认页面场地。带一丝绿灰底调的暖奶油，读作帆布、牛皮纸、或略旧的招贴。
- **黑**（`{colors.black}` — #000000）：深色场地。纯黑，用于议程式与分节断口页，那里文字反转成骨色。
- **墨**（`{colors.ink}` — #0A0A0A）：浅表面上的近黑文字。比纯黑略柔，读作墨而非数字。
- **纸**（`{colors.paper}` — #F4EFE0）：比骨色更浅的奶油，用于需要在骨色场地上显得"更轻"的卡片（矩阵表、图表框、时间轴条）。
- **赭**（`{colors.sienna}` — #A06A3C）：暖棕橙。强调里最土气的，流程步骤、原则卡。
- **洋红**（`{colors.magenta}` — #C73B7A）：饱和复古粉红。最响的暖强调，封面、引文、陈述、矩阵"否"胶囊。
- **橙**（`{colors.orange}` — #EE7A2E）：亮橙。系统最常用的强调，分节断口、原则卡、封面标记、统计卡。
- **青**（`{colors.teal}` — #2D7E73）：深蓝绿。橙的冷对位，流程卡、矩阵"是"胶囊、图表点缀。
- **蓝**（`{colors.blue}` — #3F73B7）：中调工艺蓝。用于第五步流程卡与冷变化。
- **芥末**（`{colors.mustard}` — #D8A93B）：饱和黄橙。动作条、统计卡、矩阵"部分"胶囊。
- **橄榄**（`{colors.olive}` — #6F7A2E）：柔化黄绿。用得最少的强调，预留给七连调色板或第六位卡片求变化。

### 默认值

- **默认页面场地**：内容页 `{colors.bone}`，议程式、分节断口、统计标题、含引文面板的页 `{colors.black}`。
- **默认主文字色**：骨 / 纸 / 浅强调表面上 `{colors.ink}`，黑 / 青 / 蓝 / 深强调表面上 `{colors.bone}`。
- **各强调上默认文字色**：赭、洋红、橙、芥末、橄榄、纸上用墨（暖或中调强调保持墨），青、蓝、黑上用骨色（冷 / 深强调翻成骨色）。
- **分节默认强调（单色瞬间）**：`{colors.orange}`，系统最响、最常用的强调。
- **暖色瞬间默认强调**：`{colors.magenta}` 或 `{colors.orange}`。
- **冷色瞬间默认强调**：`{colors.teal}`。
- **标注 / 动作条默认强调**：`{colors.mustard}`。
- **填充上文字默认规则**：文字绝不反转成白。深填充上的浅文字始终是 `{colors.bone}`，绝非白。

### 矩阵胶囊颜色惯例

比较矩阵里，状态胶囊遵循固定惯例：
- `{colors.teal}` 填充配骨色文字 = 是 / 肯定
- `{colors.mustard}` 填充配墨文字 = 部分 / 有限定
- `{colors.magenta}` 填充配骨色文字 = 否 / 否定
- `{colors.paper}` 填充配墨文字与 1.5px 墨边框 = 注 / 批注

矩阵之外，强调可互换。流程卡可以是洋红或青而不传达是 / 否，那里颜色是装饰，不具语义。

## 排印

### 字族

Stencil & Tablet 跑**三款字族**加一款仅展示用的专家字面：

- **Stardos Stencil**（`{typography.cover-hero.fontFamily}`）：单字重（700，引文配 400 斜体）的镂版展示字面。每个字形里的断墨缺口是系统身份。用于从 24px 矩阵头到 540px 分节数字的每个标题、每个数字、每个精选镂版瞬间。
- **Bowlby One**：单一用途的超重展示字面，只用于引文面板里 320px 的引号标记。这款字面与 Stardos Stencil 视觉语域不同（更胖、更实），预留给那一个元素。
- **Barlow Condensed**（`{typography.topbar.fontFamily}`）：高窄怪诞体，字重 500–900。承载每个全大写外壳、每个元数据标签、每个胶囊、每个图例项、每条页脚、每个辅助标签。窄身与重字重让它能在小尺寸（18–32px）塞下紧凑的全大写行。
- **Inter**（`{typography.body.fontFamily}`）：人文怪诞体，字重 400–600。预留给 18–24px 的正文段与卡片正文。Inter 是系统的"安静"声部，用于句式散文，那里 Barlow 会太响。

情绪分工是：Stardos = 尺度与标牌，Barlow = 元数据与标签，Inter = 正文，Bowlby = 仅引号标记字形。

### 招牌处理

以下处理**只要用到对应元素类型就不可省略**：

- **每个标题都全大写。** Stardos Stencil 在任何尺寸、任何语境下都跑全大写。本系统不存在句式镂版文字。
- **每个外壳、元数据、胶囊、图例元素都是全大写 Barlow Condensed、至少 0.04em 字距**（多数 0.06–0.14em）。不加字距的 Barlow Condensed 读作坏了。
- **数字始终是字重 700 的 Stardos Stencil**，绝非字重 400、绝非别的字面。连小数字（24px 矩阵头）也守惯例。
- **540px 分节断口数字始终以饱和强调渲染在深色（`{colors.black}` 或近黑）场地上**，典型 `{colors.orange}` 或 `{colors.magenta}`。浅场地上的 540px 数字会破掉分节断口语域。
- **石板卡始终在标题上方带一个数字。** 没有数字的石板不是石板，只是通用卡片。数字是石板的定义性特征。
- **统计数字用 vertical-align top 的 Barlow Condensed 上标后缀**作单位（% 号、×、K、M）。后缀跑 40px / 字重 800 / Barlow。
- **Inter 正文始终句式大写。** 把 Inter 全大写的会破掉让它读作"安静声部"的反差。
- **引文面板始终用 Bowlby One 作引号标记字形（而非 Stardos Stencil）。** 那一处元素上更胖的字面不可商量。

### 排印原则

字族阶梯固定：Stardos 作镂版展示与数字，Barlow 作全大写外壳 / 元数据 / 胶囊，Inter 作句式正文，Bowlby 作单一引号标记应用。跨轨道，例如用 Stardos 排正文、或用全大写 Inter 做外壳，会破掉排印语域。

行高在展示尺度上紧（数字与标题 0.8–0.92），正文放开到 1.4–1.45。镂版标题字距在大尺寸上略负（–0.005 到 –0.02em），外壳与标签带宽裕正字距（0.04–0.14em）。各尺寸数字都用负字距（典型 –0.02em）。

正文里不用粗体。Inter 里的强标签保持字重 400，强调靠切到全大写 Barlow Condensed，而非把 Inter 加粗。

## 布局

### 画布系统

Stencil & Tablet 经 `<deck-stage>` 组件以**固定 1920×1080 画布**为目标。布局用距页边的绝对定位。顶部外壳坐在 top: 48px、left/right: 64px，底部外壳在 bottom: 36px、left/right: 64px。卡片网格从这些外壳位置内缩，卡间 22–28px 间隙。

### 内边距与间隙比例

| Token | 值 | 用途 |
|---|---|---|
| `{spacing.pad-outer}` | 64px | 标准页面左右内缩 |
| `{spacing.pad-top}` | 48px | 外壳顶部内缩 |
| `{spacing.pad-bottom}` | 36px | 外壳底部内缩 |
| Internal card pad | 24–38px | 卡片内部内边距（紧凑到宽绰） |
| `{spacing.gap-card}` | 22–28px | 一行或网格里卡片间间隙 |

### 外壳画框

每张标准页都带顶部外壳与页脚外壳：

- **顶条**：左对齐分节名 + 右对齐元列（一两列 24px Barlow Condensed 标签）。两者全大写、窄身、重字重。
- **页脚**：左对齐日期或页标记 + 右对齐文稿名。两者全大写 Barlow Condensed 22px / 0.75 不透明度。

封面、议程、分节断口、引文面板、CTA 页通常省掉标准外壳，那些布局自带布局专属的顶部标签（封面的 "super" + 锁定、分节断口的 eyebrow 等）。

## 纵深与层级

Stencil & Tablet **按设计是扁平的**。没有投影，没有 box-shadow，没有渐变。纵深完全来自：

- **色块**：骨色场地上的饱和强调填充。洋红石板挨着青石板读作两个不同表面，因为颜色承载了分隔。
- **圆角外壳**：每张卡片 22–26px border-radius 柔化形态，让眼睛读作"石板"而非"矩形"。
- **石板叠放次序**：石板是扁平的兄弟，绝不堆叠。没有卡片坐在另一张卡片上。

唯一例外是深色议程布局上的**有机形状背景**：SVG 色块形状以强调色绝对定位坐在每个议程项背后，数字 / 标签以 z-index 浮在上面。这是系统里唯一的 z-index。

## 形状与处理

### 圆角

| 值 | 用途 |
|---|---|
| 999px（胶囊） | 状态胶囊（是 / 部分 / 否 / 注） |
| 26px | 石板卡、原则卡、引文面板、CTA 面板 |
| 22px | 标准卡片、动作条、流程节点、矩阵表、图表框、咨询栏、统计卡 |
| 18px | 装饰时间轴条 |
| 14px | 封面标记（小锁定方块）、时间轴石板 |
| 0（方） | 图表绘图框边缘（2px 实黑绘图框）、图例条、有机形状 SVG（按定义无 border-radius） |

卡片一律 22–26px 圆角。方角只出现在图表绘图框（轴线几何要求）与图例条（图表图例的扁平 32×6px 矩形）上。

### 边框粗细

- **2px 实 `{colors.ink}`**：用于图表绘图框（图表区左与下边缘）与咨询栏 h3 下划线。
- **1.5px 实 rgba(10,10,10,0.35)**：用于矩阵单元边框。矩阵是系统里最密的表，需要可见的单元分隔。
- **1px 虚线 rgba(10,10,10,0.18–0.35)**：用于图表绘图区内网格线与来源归属顶线。
- **2px 实 `{colors.ink}` 作竖分隔**：用于动作条内与咨询头里隔开标签与标题。

### 装饰元素类型

**石板卡**：系统的同名容器。22–26px 圆角卡，装一个 220px+ 镂版数字，下压镂版标题，再压 Inter 正文。数字填满卡上半部，标题与正文经 `margin-top: auto` 坐在底部。背景取任一强调填充，文字色随表面（暖 / 浅填充上墨，冷 / 深填充上骨色）。

**彩色卡**：任一强调填充的通用 22–26px 圆角卡，用于原则、流程节点、统计、咨询栏。含镂版标题、可选正文、可选强调元素。

**分节断口数字**：540px 镂版数字，强调色（典型 `{colors.orange}` 或 `{colors.magenta}`），绝对坐在黑场地上，配右上一条小 Barlow eyebrow 与右下一条 120px 镂版标题。数字*就是*布局。

**动作条**：全宽芥末填充圆角卡（22px 半径）横贯页靠近顶部，内含左对齐全大写 Barlow 标签、一条竖墨线分隔、一条 34px 镂版标题。用于重要的分节开场标注。

**状态胶囊**：999px 全圆胶囊，装全大写 Barlow 文字。按矩阵状态颜色编码（青 / 芥末 / 洋红 / 纸描边）。

**矩阵表**：纸填充圆角卡，内含 1.5px 边框单元网格。表头行反转成黑填充配骨色镂版字。行标签单元用全大写镂版。状态单元装胶囊。

**流程节点**：小圆角卡（22px 半径），装 64px 镂版序数、28px 镂版 h3、小号 Inter 正文。流程节点坐在五连网格里，彼此间有箭头连接。

**时间轴条**：纸填充圆角卡（14px 半径）横贯流程图底部，高 50px，内含均匀铺开的全大写 Barlow 时间轴标记。

**封面锁定**：封面页底部一行，含一枚 56px 圆角方形强调标记、一组全大写 Barlow 名称 + 副标题叠排、一个镂版日期。定义封面底部的惯例。

**引文面板**：洋红填充、26px 圆角面板，填满大半页，左侧一个 320px Bowlby One 引号标记、右侧 60px 镂版引文文字。

**有机色块形状**：饱和强调色的 SVG 变形虫状形状，坐在议程项背后。色块是背景，数字与标签浮在上方。

**图例条**：扁平 32×6px 矩形（无 border-radius），取图表色，作全大写 Barlow 标签旁的图表图例色样。

**统计后缀**：40px / 字重 800、vertical-align top 的 Barlow Condensed 上标，坐在 160px 镂版数字旁。标准单位（% 号、×、K、M）。

## 该做与不该做

### 该做

- 每个标题都用字重 700 的全大写 Stardos Stencil，无论尺寸。镂版断墨字形是系统身份。
- 每个外壳、标签、胶囊、图例、页脚、元数据元素都用超重（600–900）全大写 Barlow Condensed，字距至少 0.04em。
- 把数字渲染得巨大，石板卡 220px、统计 160px、分节断口 540px。尺度是系统的主表现工具。
- 在骨色场地上以饱和强调（赭、洋红、橙、青、蓝、芥末、橄榄）铺贴卡片。色块*就是*布局。
- 每张卡片都圆到 22–26px。卡片上的方角会破掉石板语域。
- 把镂版标题与数字配 Inter 正文，响 / 静反差是排印节奏。
- 深填充上的文字用 `{colors.bone}`（而非白）。骨压黑是系统唯一的颜色反转，白会冲突。
- 一致套用矩阵胶囊惯例（青 / 芥末 / 洋红 / 纸描边），是 / 部分 / 否 / 注。惯例靠反复出现才挣得分量。
- 引文面板里的引号标记字形用 Bowlby One。那是这款字面唯一出现的地方。
- 外壳放在固定偏移（top: 48px / 64px、bottom: 36px / 64px）。标准页上外壳位置不可商量。

### 不该做

- 不要把镂版标题小写。Stardos Stencil 任何尺度下都只全大写。
- 不要把外壳或元数据排成句式。本系统里 Barlow Condensed 始终全大写。
- 不要加投影或渐变。系统是饱和色的扁平块。
- 不要把卡片、动作条、胶囊的角弄方。可接受的最小卡片半径是 22px，胶囊是 999px。
- 不要在深填充上把文字反转成纯白。用 `{colors.bone}`，米白才把系统系在骨 / 纸语域上。
- 不要用 Inter 做标题或外壳。Inter 是正文声部，从不领衔。
- 不要用 Stardos Stencil 排正文段。镂版字面在正文尺度（22px 以下）会读不了，Inter 作正文声部是有原因的。
- 不要引入第八种强调色。七强调调色板加骨 / 黑 / 纸是封闭的。
- 不要在浅场地上用分节断口的 540px 数字。超大数字式样只活在深色场地上。
- 不要用小于 22px 的间隙挤满卡片。卡片之间露出的骨色场地是结构性的。

## 响应式行为

Stencil & Tablet 是**固定 1920×1080** 系统，渲染在 `<deck-stage>` web component 内。布局用绝对像素定位，deck-stage 把整个 1920×1080 画布等比缩放适配视口。没有媒体查询。

### 缩放行为

所有元素在任何视口下保持相对位置与尺寸。540px 分节数字在 deck-stage 内部画布上仍是 540px，stage 把画布缩放到浏览器。系统依赖 deck-stage 组件做这个缩放。

### 放映行为

导航由外部 `deck-stage.js` 脚本处理。每页带一个 `data-label` 属性标识它。翻页经 deck-stage 的控件完成，某些页带 `data-om-validate="false"` 以退出某些自动校验。

### 打印行为

没有内嵌打印样式表。静态导出取决于 deck-stage 组件，生成 PDF 时每页渲染为单张 1920×1080 页。

## CJK 与国际化内容

### 推荐中文搭配

| 角色 | 拉丁字面（默认） | 中文字面 | 字重 | 说明 |
|---|---|---|---|---|
| 展示 / 封面英雄 / 分节断口 | Stardos Stencil 700 全大写 | 思源宋体 / Noto Serif SC | 900 | Stardos Stencil 的工业标牌语域最好地译到最重字重（900）的 Noto Serif SC，宋体笔画在 120–540px 尺度下承载对等视觉分量。 |
| 数字（石板、统计、超大） | Stardos Stencil 700 | 思源宋体 / Noto Serif SC | 900 | 中文文稿里以 NSC 900 渲染的中文数字（一二三四五 或 〇一二三四）能在强调填充上撑住分量。中文文稿里的拉丁 / 阿拉伯数字应保留 Stardos 以留断墨。 |
| 外壳 / 元数据 / 胶囊 | Barlow Condensed 800 全大写 | 思源黑体 / Noto Sans SC | 700–900 | Barlow Condensed 在 CDN 上没有压缩的 CJK 对应，回退到重型 Noto Sans SC。无法用更紧的 `font-stretch`，靠更短的标签。 |
| 正文 | Inter 400 | 思源宋体 / Noto Serif SC | 400 | NSC 正文贴合响 / 静反差，衬线正文略软化工业语域但保持易读。 |

### 混排策略

本模板用**策略 A**：任何渲染汉字的元素，把拉丁展示字面整体换成 CJK 展示字面。Stardos Stencil 的断墨缺口物理上绑定于拉丁字母的笔画拓扑，CDN 上没有能复现该效果的中文字面，强让 Stardos 显示 CJK 要么失败（无字形覆盖）、要么渲染出难看的回退。任何含中文的元素都把整条 `font-family` 换成 Noto Serif SC 900。

```css
font-family: 'Noto Serif SC', 'Stardos Stencil', serif;  /* display / headlines — CJK first */
font-family: 'Noto Sans SC', 'Barlow Condensed', sans-serif;  /* chrome / pills — heavy weights only */
font-family: 'Noto Serif SC', 'Inter', sans-serif;  /* body */
```

把 NSC 放在栈首意味着汉字用 NSC 渲染，同一元素里混进的拉丁 / 数字内容也会得到 NSC，于是混排行丢掉镂版语域。**建议**：带混排标题的封面页（如 `STUDIO 工作室`）拆成两个 `<span>`，一个用 Stardos 放拉丁词、一个用 NSC 900 放中文短语，尺寸调到视觉分量相配（同 px 下 NSC 900 比 Stardos 700 略重）。

### 加载

加到 `<head>`（Google Fonts 托管 Noto Serif SC 与 Noto Sans SC，两者都带字重 900）：

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Stardos+Stencil:wght@400;700&family=Bowlby+One&family=Barlow+Condensed:wght@500;600;700;800;900&family=Inter:wght@400;500;600&family=Noto+Serif+SC:wght@400;500;700;900&family=Noto+Sans+SC:wght@400;500;700;900&display=swap" rel="stylesheet">
```

Noto Serif SC 900 是关键，它是唯一能在大尺度下与 Stardos Stencil 视觉对等的字重。更轻字重（700 及以下）会让中文标题在镂版拉丁旁显"薄"。

### 通用 CJK 调整

施于任何渲染中文内容的元素（典型用 `:lang(zh)` 或 `<span lang="zh">` 限定范围）：

- **行高**：正文 1.75–1.85（Stencil & Tablet 的 1.4 Inter 默认对 CJK 笔画太紧），展示 1.15–1.25（比拉丁 0.8–0.92 松，因为 220–540px 的 CJK 字形需要纵向呼吸空间，否则笔画相撞）。
- **字距**：CJK 设 0。系统在拉丁展示上的负字距（-0.005 到 -0.02em）与 Barlow 外壳上的正字距（0.04–0.14em）对中文都是错的，CJK 字形本就预置间距，加字距要么重叠要么出现不自然的缝。
- **文字变换**：CJK 不用 uppercase。Stencil & Tablet 在拉丁里几乎把一切都全大写，在中文上这是空操作，但要确保没有父级规则尝试它（某些浏览器可能渲染得不可预测）。
- **全角标点**：用 `，。：；！？`（全角）而非 `,.:;!?`（半角）。全角形式自带周围留白并贴合 CJK em 框。
- **展示标题不加句号**：中文标题去掉末尾 `。`，标题的视觉收束已足够。
- **盘古之白（Pangu spacing）**：在 CJK 与相邻拉丁 / 数字间插入一个窄空格。写 `使用 Claude` 而非 `使用Claude`，`2024 年` 而非 `2024年`。本系统里尤其要紧，因为 Stardos 数字常常挨着中文标签。
- **一句一款字体**：不要在同一行里混 NSC 与 Noto Sans SC。衬线 / 无衬线切换应发生在元素边界，而非短语中间。

### 本系统的美学提示

Noto Serif SC 900 压在饱和强调填充（洋红、橙、青）上，很好地复现系统海报般响亮的语域，厚重宋体笔画与 Stardos Stencil 粗壮镂版字形视觉分量相近。系统身份（工业标牌 / 市政镂版）在 CJK 里略偏向"中文报纸标题"，是个相关但不同的语域，对工业镂版感要紧的项目，拉丁词倚重 Stardos，并接受纯中文标题会读成权威的报纸招贴字、而非滑板板面镂版。

矩阵胶囊惯例（青 = 是、芥末 = 部分、洋红 = 否）直接迁移，把胶囊里的全大写 Barlow 文字换成 NSC 700 句式中文标签（`是` / `部分` / `否`）。胶囊宽度可能因中文变长（单字标签最紧），保留 999px 半径、接受略宽的胶囊。

540px 分节断口数字式样是系统最强的瞬间之一，配中文格外漂亮，`一` `二` `三` 以 540px NSC 900 渲染在黑场地上的视觉权威，与同尺寸 Stardos 相当。两位数字时 NSC 900 在同 px 下比 Stardos 窄，可考虑提到 600–620px，保住"数字填满画布"的语域。

### 已知 CJK 缺口

- Barlow Condensed 没有压缩的 CJK 对应。系统全大写、重、窄、加字距的外壳美学无法复现，Noto Sans SC 900 是最接近的回退但缺压缩比例。接受中文外壳会比拉丁外壳略宽。
- Bowlby One 仅拉丁、且只活在一处（引文面板里的 320px 引号标记）。中文引文面板可换成以 NSC 900 在 320px、原 `{colors.magenta}` 或 `{colors.teal}` 下渲染的 `「`（全角左角引号）或 `『`，这是通行的中文起始引号字形，不需要 Bowlby 字重也能读对。
- Stardos Stencil 单字重（700）。NSC 出厂 400、500、700、900，系统给 Stardos 的一切都指定字重 700，但 CJK 应用 NSC 900 配视觉分量，规格里的"字重 700"是不适用的拉丁惯例。
- 胶囊惯例的 `letter-spacing: 0.04–0.14em` 在 CJK 上无意义，任何中文胶囊内容都应归零。

## 迭代指南

1. 任何新标题都用字重 700 的全大写 Stardos Stencil。镂版断墨是系统最易认的特征。
2. 任何新卡片都用 22–26px border-radius 与七色调色板里的饱和强调填充。石板形制是默认容器。
3. 任何新石板都必须在标题上方含一个镂版数字。没有数字的石板只是卡片。
4. 任何新外壳、标签、胶囊、图例都用字重 600–900、至少 0.04em 字距的全大写 Barlow Condensed。
5. 任何新正文段都用 18–24px 的 Inter。Inter 是系统唯一的句式字面。
6. 矩阵布局里的状态胶囊遵循固定颜色惯例（青 / 芥末 / 洋红 / 纸描边）。别造带新颜色的新状态，靠复用既有调色板扩展。
7. 数字始终跑字重 700 配负字距（典型 –0.02em）。更小字重的镂版数字会破掉系统。
8. 冷填充（青、蓝、黑）把文字翻成 `{colors.bone}`。暖与中调填充（赭、洋红、橙、芥末、橄榄、纸、骨色）保持 `{colors.ink}`。
9. 分节断口页用 540px 数字 + 120px 标题 + 黑场地式样。别把分节断口压进更小的画框，尺度*就是*断口。
10. 卡片之间与周围露出的骨色场地是结构性的。别为塞更多内容缩小它，内容放不下就减少内容。

## 已知缺口

- 系统依赖外部 `deck-stage.js` 脚本做页面缩放与导航。缺它页会按固有 1920×1080 渲染。
- 四款字族（Stardos Stencil、Bowlby One、Barlow Condensed、Inter）都从 Google Fonts 加载。字体加载失败时，回退（serif、sans-serif、Helvetica、Arial）会彻底丢掉镂版与窄身个性。
- Stardos Stencil 是单字重字面，没有字重轴。系统用 font-weight: 700 作标签，但这款字面实际只有一个字重，在 quote-text token 里指定 400 渲染出来几乎一样。
- Bowlby One 恰好只出现在一处（320px 引号标记）。为单个字形加载一款重量级资产，若引文面板不用，Bowlby One 就是字体加载里的死重。
- 议程页上的有机形状 SVG 色块是带手调贝塞尔曲线的行内 SVG 路径，不是参数化的，加新形状得画出来。
- 图表绘图 SVG 在固定宽高比 SVG 里用硬编码坐标，数据更新需手工重算点位置。
- 七强调调色板在矩阵之外并不严格把颜色映射到语义角色。文稿可遵循松散惯例（橙 = 主、青 = 次），但系统不强制。
- 封面英雄、numeral-tablet、section-headline 都用朝负方向的宽裕字距，视口缩放极小时字形可能相碰。deck-stage 的等比缩放实际上避免了这一点。
