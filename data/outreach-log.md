## Issue 口径（模板见提交记录）

- 明说译文在**独立仓库**，不要求上游托管、审阅或维护
- 明确标注「非官方、社区维护的翻译」，除非维护者另行授权，不声称官方中文版
- 只求 README 一行链接（Translations / Community 区块），中文用户可找到持续维护的版本而非随手 fork
- 被拒完全接受：保持独立仓库、不开 PR、不跟进
- 附本仓库合规说明：GLOSSARY、License 声明与版权行、每日 CI 比对上游 HEAD 并同步原样件；收录清单链接

## 跟进约定

- 维护者回复后更新上表状态（同意 / 婉拒 / 无回应）
- 同意 → 起草最小 README 改动 PR（只加一行链接，不动其他内容），合并前请本仓库所有者确认
- 婉拒 → 标记「不再跟进」，保留独立仓库，不改变译文内容
- 四周无回应视为默认婉拒，不催、不重开
